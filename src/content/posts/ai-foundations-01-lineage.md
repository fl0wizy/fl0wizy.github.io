## 먼저 단어의 포함 관계

- **인공지능(AI):** 지능적인 일을 하는 기계를 만드는 모든 시도
- **기호주의:** AI 중에서 사람이 규칙을 직접 쓰는 방식. 데이터로 배우지 않는다
- **기계학습(= 머신러닝):** AI 중에서 데이터로부터 패턴이나 판단 기준을 배우는 방식. 정답을 함께 주는 지도학습도 있고, 정답 없이 구조를 찾는 비지도학습도 있다
- **고전 기계학습:** 기계학습 중에서 주로 사람이 설계한 특징을 바탕으로 예측 함수나 데이터의 구조를 배우는 방식. 회귀, KNN, 결정트리, **SVM**, 앙상블 (2\~7장)
- **딥러닝:** 기계학습 중에서 층을 깊게 쌓은 신경망이 특징까지 스스로 배우는 방식. CNN, RNN, Transformer (8\~14장)

```py
인공지능 (AI) — 사람처럼 지능적인 일을 하는 기계를 만드는 모든 시도
├── 기호주의 AI — 사람이 규칙을 직접 쓴다 (전문가 시스템, 시그니처 기반 IDS)
│                 ※ 데이터로 배우지 않으므로 머신러닝이 아니다
│
└── 머신러닝 (= 기계학습) — 데이터에서 패턴이나 판단 기준을 학습한다
    ├── 고전 머신러닝 — 주로 사람이 설계한 특징에서 예측 함수·데이터 구조를 학습
    │     선형·로지스틱 회귀, KNN, 결정트리, SVM, 앙상블(랜덤 포레스트, XGBoost),
    │     k-means, PCA                                   ← 강의 2~7장
    │
    └── 신경망 — 뉴런을 흉내 낸 층으로 함수를 만든다
          ├── 얕은 신경망: 퍼셉트론, 은닉층 1개짜리 MLP   ← 8장 앞부분
          └── 딥러닝 — 층을 깊게 쌓아 특징까지 단계적으로 학습
                DNN, CNN, RNN·LSTM, Transformer          ← 8, 10~14장
```

| 계보 | 핵심 답 | 대표 기법 |
| --- | --- | --- |
| **기호주의** (Symbolic AI) | 사람이 지식을 규칙으로 적는다 | 전문가 시스템, 시그니처 기반 IDS |
| **고전적 통계 학습** | 여기서는 사람이 설계한 특징에서 경계나 함수를 배우는 방식을 중심으로 본다 | 회귀, KNN, 결정트리, SVM, 앙상블 |
| **연결주의** (Connectionism) | 뉴런을 흉내 낸 망이 특징까지 스스로 배운다 | 퍼셉트론, 역전파, CNN, RNN, Transformer |

이 글에서는 AI의 발전을 기호주의, 고전적 통계 학습, 연결주의라는 세 흐름으로 따라가 본다. 다만 서로 완전히 갈라지는 분류는 아니다. 신경망과 딥러닝도 데이터에서 배우므로 통계적 학습에 포함될 수 있다. 여기서 “통계적 학습”이라고 줄여 부르는 부분은 주로 사람이 특징을 설계하던 고전적 방식을 뜻한다. 세 흐름은 차례로 등장해 교체된 것이 아니라, 시기를 겹쳐 가며 경쟁했고 주도권이 옮겨 갔다.

시대별 AI 계보의 변화를 정말 가볍게 요약하자면 기호주의 → 연결주의(퍼셉트론) → 통계적 학습 → 연결주의(transformer, GPT)

즉, 우리가 사용하는 GPT나 Claude 같은 대규모 언어 모델은 연결주의에 속한다. Codex와 Claude Code는 그런 모델을 도구와 연결해 실제 일을 하게 만드는 앱이다. 모델 자체와 그것을 감싼 실행 프로그램은 다음 하네스 페이지에서 구분하겠다.

더 자세한 이야기는 하나하나 서술해보겠다. 그리고 각각의 상세 기법에 대해서는 따로 다룰 예정이다.

- 기호주의
- 통계적 학습
- 연결 주의

## 세 가지 계보

### 기호주의

기호주의는 사람이 규칙을 넣는 것이다. 예를 들어 네트워크 침입 탐지를 하는 AI라고 했을 때 그 logic이 아래와 같은 것이다.

```txt
IF   목적지 포트가 22(SSH)이고
AND  같은 출발지에서 60초 안에 접속 시도가 5번을 넘으면
THEN "SSH 무차별 대입 공격" 경보를 낸다
```

이 기호주의가 AI의 초창기를 이끌었지만 아래와 같은 한계에 부딪혔다.

- 변종에 약하다 : 공격자 혹은 스팸을 넣는 사람이 “무료”를 “무.료”나 “free”로 바꾸면 규칙이 통과한다. 랜섬웨어가 메시지 문장을 조금만 바꿔도 규칙이 이를 놓칠 수있는 것이다.

- 예외가 끝없이 늘어난다 : “60초에 5번 이상 접속이면 공격”이라고 했더니, 자동 백업 스크립트도 걸린다. 예외 규칙을 넣으면 그 예외의 예외가 또 생긴다. 규칙끼리 서로 충돌하기 시작한다.

- 규칙으로 적을 수 없는 지식이 있다 : 숙련된 보안 분석가는 로그를 보고 “뭔가 이상하다”고 느끼지만, 그 감각을 IF-THEN으로 옮기지 못한다. 사진 속 고양이를 알아보는 능력도 마찬가지이다.

- 사람의 시간이 병목이다 : 전문가를 인터뷰하고 규칙을 적고 유지하는 데 드는 비용을 “지식 획득 병목”이라고 부른다. 1980년대 전문가 시스템이 무너진 주된 이유이다.

그렇다고 해서 규칙 기반이 완전 사라진 것은 아니다. 보안에서는 지금도 규칙 기반 탐지가 첫 번째 방어선이다. 알려진 공격은 규칙이 가장 빠르고 정확하며, 왜 탐지했는지 바로 설명된다. 그래서 실무에서는 알려진 공격은 규칙으로, 새롭거나 애매한 것은 기계학습으로 나눠 맡기는 경우가 많다.

### 통계적 학습

위의 기호주의의 한계로 규칙과 판단 기준을 데이터에서 찾게 하는 시스템이 필요해졌다. 여기서는 먼저 지도학습을 보자. 사람이 규칙 대신 데이터와 정답을 주면, 기계가 그 데이터에서 판단 기준을 찾는다. 다만 아래 예에서는 데이터를 어떤 숫자로 표현할지, 즉 특징(feature)은 사람이 정한다. 정답 없이 비슷한 자료를 묶는 k-means나 중요한 변화 방향을 찾는 PCA도 기계학습이지만, 지금의 공격·정상 분류와는 학습 방식이 다르다.

같은 SSH 무차별 대입 탐지를 통계적 학습으로 만들면 다음과 같다.

1. 사람이 특징을 설계한다 : 60초간 접속 시도 횟수, 로그인 실패 비율, 시도한 계정 수, 접속 시간대
2. 과거 기록에 정답을 붙인다 : 수만 건의 접속 기록에 “공격” 또는 “정상” 라벨을 단다.
3. 모델이 경계를 찾는다 : SVM 같은 모델이 이 특징들로 이루어진 공간에서 공격과 정상을 가장 잘 나누는 경계를 계산한다.

```txt
[시도 횟수, 실패 비율, 계정 수, 시간대]    정답
[   48,      0.98,      35,     3시 ]  →  공격
[    6,      0.00,       1,    14시 ]  →  정상 (자동 백업 스크립트)
[   12,      0.75,       9,     2시 ]  →  공격
```

이렇게 학습한 모델은 “시도 횟수가 많아도 실패 비율이 0이면 정상”이라는 것을 사람이 규칙으로 적지 않아도 스스로 배운다. 기호주의에서 끝없이 늘어나던 예외 규칙이 데이터 안에서 자동으로 처리되는 것이다.

통계적 학습은 기호주의의 한계를 다음과 같이 풀었다.

- 변종에 약하다 → 값 하나가 아니라 여러 특징의 조합으로 판단하므로, 일부가 조금 바뀌어도 잡아낸다. 새 변종이 나오면 규칙을 고치는 대신 데이터를 추가해 다시 학습한다.
- 예외가 끝없이 늘어난다 → 예외 사례가 데이터에 들어 있으면 경계가 알아서 조정된다.
- 사람의 시간이 병목이다 → 전문가는 규칙을 쓰는 대신 정답 라벨만 붙이면 된다.

대표 기법은 회귀, KNN, 결정트리, SVM, 앙상블이다. 특히 1990년대부터 2011년경까지는 SVM이 주류였다. 학습 문제를 볼록 최적화로 다룰 수 있고, 왜 잘 되는지에 대한 이론적 근거가 있으며, 적절한 특징이 있으면 비교적 적은 데이터에서도 잘 작동했기 때문이다. 볼록 최적화란, 더 나쁜 지역 최솟값에 갇히지 않고 전체 최솟값을 찾을 수 있는 형태의 문제라는 뜻이다. 그렇다고 모든 조건에서 해가 반드시 하나라는 뜻은 아니다.

→ 각 기법에 대해서는 따로 다루겠다.(현재 페이지는 전체적인 흐름만 잡기 위함이다)

하지만 통계적 학습도 아래와 같은 한계에 부딪혔다.

- 특징은 여전히 사람이 만든다 : 모델의 성능이 사람이 어떤 특징을 뽑아 주느냐에 달려 있다. 사람이 “로그인 실패 비율”이라는 특징을 떠올리지 못하면 모델도 그것을 배울 수 없다. 병목이 “규칙 작성”에서 “특징 설계”로 옮겨 갔을 뿐이다.

- 원시 데이터를 직접 다루지 못한다 : 이미지의 픽셀, 악성코드의 바이트, 로그의 문장을 그대로 넣으면 성능이 크게 떨어진다. 사람이 먼저 의미 있는 숫자로 요약해줘야 한다.

- 데이터가 커지면 감당하지 못한다 : 커널 SVM은 데이터 수의 제곱에 비례해 계산량이 늘어난다. 데이터가 수백만 개로 늘어나자 학습 자체가 어려워졌다.

이 한계는 인터넷으로 데이터가 폭증하면서 결정적인 문제가 되었다. 데이터는 넘쳐나는데 사람이 그 특징을 일일이 설계할 수 없게 된 것이다. 이 지점에서 특징까지 스스로 배우는 연결주의가 다시 주목받게 된다.

참고로 위에서 연결주의가 다시 시작되었다고 말한 것은 사실 역사적으로 보면 연결주의가 통계적 학습보다 먼저 시작되었기 때문이다. 퍼셉트론은 1958년이고, SVM은 1990년대이다. 그래서 2010년대의 딥러닝은 사실 “다시” 주목받은 것이 맞다.

그렇다고 통계적 학습이 사라진 것은 아니다. 표 형태로 정리된 데이터에서는 지금도 XGBoost 같은 트리 앙상블이 딥러닝과 대등하거나 더 강하다. 보안에서도 네트워크 흐름 통계처럼 이미 숫자로 정리된 데이터는 통계적 학습이 강력한 기준선이며, 결정 트리처럼 판단 근거를 설명할 수 있는 모델은 탐지 이유를 보여 줘야 하는 현장에서 여전히 쓰인다.

### 연결주의

연결주의는 사람 뇌의 뉴런을 흉내 낸 단위들을 연결해 망(신경망)을 만들고, 그 연결의 세기(가중치)를 데이터로 학습하는 방식이다. 앞서 본 고전적 방식과 비교할 때, 특히 깊은 신경망은 특징을 여러 단계에 걸쳐 함께 배울 수 있다는 점이 중요하다. 신경망도 통계적 학습의 한 방식이며, 단순한 퍼셉트론부터 모두 복잡한 특징을 자동으로 배우는 것은 아니다. 사람은 여전히 입력을 준비하고 학습 목표를 정해야 한다. 정답을 주는 지도학습도 있고, 데이터 자체에서 학습 문제를 만드는 자기지도 학습도 있다.

사실 연결주의는 새로운 방식이 아니다. 기호주의와 거의 같은 시기인 1958년, 퍼셉트론이 “데이터로 배우는 기계”를 처음 선보였다. 하지만 층이 하나뿐이라 직선 하나밖에 긋지 못했고, 직선으로 나눌 수 없는 가장 단순한 문제(XOR)조차 풀지 못한다는 것이 1969년에 증명되면서 한동안 잊혔다. 1986년 역전파가 등장하면서 층을 여러 개 쌓은 신경망을 학습할 수 있게 되었지만, 데이터가 적고 컴퓨터가 느린 시대에는 학습이 불안저해서 1990년대에는 통계적 학습에 밀렸다.

- 퍼셉트론 : 입력에 가중치를 곱해 더하고, 합이 기준을 넘으면 1을 내는 가장 단순한 신경망
- 은닉층 : 입력층과 출력층 사이의 층. 입력을 새로운 특징으로 바꾸는 역할을 한다.
- 역전파 : 출력 오차를 뒤로 전달하며 모든 가중치를 얼마나 고칠지 계산하는 방법

그러다 2010년대에 세 가지가 동시에 갖춰졌다. 인터넷이 만든 대규모 데이터, 계산을 수십 배 빠르게 한 GPU, 그리고 층을 깊게 쌓아도 학습이 무너지지 않게 하는 학습 요령(ReLU, 좋은 초기화, 정규화 등)이다. 이 덕분에 층을 수십\~수백 개 쌓은 딥러닝이 가능해졌고, 2012년 이미지 인식 대회에서 사람이 설계한 특징을 쓰는 방법을 크게 앞지르며 연결주의는 다시 주류가 되었다.

같은 SSH 무차별 대입 탐지를 연결주의로 만들면 다음과 같다. 사람이 “실패 비율”, “시도 횟수” 같은 특징을 뽑지 않고, 로그를 거의 그대로 넣는다.

```txt
03:12:01  10.0.0.5  admin  FAIL
03:12:03  10.0.0.5  root   FAIL
03:12:04  10.0.0.7  test   FAIL
...                                 →  모델이 순서 패턴 자체를 학습  →  공격
```

이렇게 하면 사람이 미처 떠올리지 못한 패턴도 잡을 수 있다. 예를 들어 여러 IP에서 몇 시간에 걸쳐 조금씩 나눠 시도하는 공격은, “60초 안에 5번”이라는 규칙에도, 사람이 설계한 특징에도 잘 걸리지 않는다. 신경망은 로그의 흐름 전체에서 이런 패턴을 스스로 찾아낸다.

연결주의는 통계적 학습의 한계를 다음과 같이 풀었다.

- 특징은 여전히 사람이 만든다 → 모델이 원시 데이터에서 특징을 단계적으로 학습한다. 앞쪽 층은 단순한 패턴을, 뒤쪽 층은 그 패턴들을 조합한 복잡한 패턴을 배운다.
- 원시 데이터를 직접 다루지 못한다 → 이미지의 픽셀(CNN), 로그와 문장의 순서(RNN, Transformer)를 그대로 입력으로 받는다.
- 데이터가 커지면 감당하지 못한다 → 데이터를 조금씩 나눠 학습(미니배치)하고 GPU로 병렬 계산하므로, 데이터가 많을수록 오히려 성능이 좋아진다.

연결주의의 마지막 큰 도약은 2017년의 **Transformer**다. 이전의 순환 신경망(RNN)은 문장을 한 단어씩 순서대로 처리해서 느렸고, 문장이 길면 앞 내용을 잊었다. Transformer는 어텐션으로 문장 전체를 한꺼번에 보고 필요한 부분에 집중하게 만들어 두 문제를 동시에 풀었다. 모든 단어를 동시에 계산할 수 있어서 GPU를 최대로 활용할 수 있었고, 덕분에 모델과 데이터를 거대하게 키운 GPT 같은 대규모 언어 모델(LLM)이 등장한 것이다. 이 모델들은 사람이 정답을 붙이지 않은 인터넷 텍스트에서 “다음 단어 맞히기”로 학습하기 때문에, 라벨 비용이라는 오래된 문제도 피해갔다.

- 어텐션 : 지금 필요한 정보가 입력의 어디에 있는지 점수를 매기고, 그 점수만큼 가중해서 보는 방법

하지만 연결주의도 아래와 같은 한계를 가지고 있다.

- 데이터와 계산을 많이 먹는다 : 데이터가 적으면 오히려 통계적 학습보다 못하다. 대규모 모델은 학습에 박대한 GPU 비용이 든다.

- 판단 근거를 설명하기 어렵다 : 수억 개의 가중치가 얽혀 있어 “왜 이 접속을 공격으로 판정했는가”를 사람이 읽어 내기 어렵다. 보안 분석가는 근거를 알아야 대응할 수 있다.

- 작은 변형에 속을 수 있다 : 사람이 보기엔 거의 같은 입력을 살짝 조작해서 모델의 판단을 뒤집는 공격(적대적 공격)이 가능하다. 공격자가 존재하는 보안 분야에서는 특히 큰 약점이다.

- 데이터의 편향을 그대로 배운다 : 특정 환경에서 수집한 데이터로 학습하면, 공격 자체가 아니라 수집 환경의 흔적을 배울 수 있다.

현재 GPT 같은 프론티어 모델은 연결주의에 속한다. 지식이 사람이 쓴 규칙이 아니라 학습된 가중치 안에 저장되어 있기 때문이다. 다만 실제로 서비스되는 AI는 모델만으로 작동하지 않는다. 계산기나 검색 같은 도구를 호출하고, 사람이 정한 안전 규칙을 따른다. 이는 가드레일, tooling, MCP와 같은 개념이다. 즉 모델은 연결주의이고, 그것을 감싼 시스템은 세 계보가 섞인 형태이다.

| 계보 | 규칙을 누가 만드나 | 특징을 누가 만드나 | 넘어선 한계 | 남은 한계 |
| --- | --- | --- | --- | --- |
| 기호주의 | 사람 | 사람 | — | 규칙을 끝없이 고쳐 써야 함 |
| 고전적 통계 학습 | 데이터에서 학습 | 주로 사람 | 규칙 작성 | 특징 설계가 병목 |
| 연결주의, 특히 딥러닝 | 데이터에서 학습 | 입력 준비는 사람, 내부 특징은 데이터에서 학습 | 특징 설계의 부담 | 데이터·계산 비용, 설명 어려움 |

그리고 세 계보는 지금도 함께 쓰인다. 보안 현장에서는 알려진 공격은 규칙(기호주의)으로, 정리된 수치 데이터는 트리 앙상블(통계적 학습)로, 로그/바이너리/문장 같은 원시 데이터는 신경망(연결주의)으로 나눠 맡는 경우가 많다.

## 시대별 변화

앞에서는 같은 SSH 공격 탐지 문제를 놓고 “누가 규칙과 특징을 만드는가”를 비교했다. 이제는 “왜 그 방식이 그 시기에 주목받았는가”를 시간 순서로 보자. 앞부분이 작동 방식의 비교라면, 아래는 데이터와 계산 환경이 달라지면서 선택이 바뀐 과정이다.

### 1. 규칙을 사람이 직접 쓴다 → 기호주의의 시작 (1950\~1960년대)
1956년 다트머스 회의에서 "인공지능(AI)"이라는 이름이 처음 붙었다. 당시 연구자들은 사람이 아는 지식을 "만약 \~이면 \~이다(IF-THEN)" 규칙으로 적어 넣으면, 컴퓨터가 그 규칙을 조합해 결론을 낼 것이라고 생각했다. 이것이 기호주의다.

- 배경 : 컴퓨터는 방 하나 크기에 계산 능력은 지금의 계산기 수준이었다. 데이터도 사람이 손으로 만든 수백 개 정도였다.
- 기호주의의 강점 : 체스, 수학 정리 증명처럼 규칙이 명확한 문제에서 빠르게 성과를 냈다.
- 기호주의의 한계 : 규칙으로 적을 수 없는 일이 많았다. "사진 속 고양이를 알아보는 법"은 IF-THEN으로 적을 수 없다.
- 보안 예 : 지금도 쓰는 시그니처 기반 탐지가 이 방식이다.

---

### 2. 데이터로 배우는 첫 기계 → 퍼셉트론의 등장과 좌절 (1958\~1969)
1958년 Rosenblatt는 뇌의 뉴런을 흉내 낸 퍼셉트론을 만들었다. 규칙을 적지 않고, 기계가 데이터를 보며 스스로 배우게 한 첫 시도였다. 이것이 연결주의의 출발이다.

- 핵심 아이디어 : 입력마다 중요도를 나타내는 숫자(가중치)를 곱해 더하고, 합이 기준을 넘으면 1을 낸다. 틀릴 때마다 가중치를 조금씩 고친다.
- 연결주의의 한계 : 층이 하나뿐이라 직선 하나밖에 긋지 못했다. 1969년 Minsky/Papert가 XOR(두 입력 중 정확히 하나만 1일 때 1)조차 풀지 못한다는 것을 증명했다. 층을 쌓으면 된다는 것은 짐작했지만, 쌓은 층을 학습시킬 방법(역전파)이 없었다.
- 당시의 판단 : "학습시킬 방법도 없는 망보다, 사람이 규칙을 넣는 쪽이 지금 당장 된다." → 연구비와 관심이 기호주의로 옮겨갔다.

---

### 3. 신경망의 겨울 → 기호주의는 전문가 시스템으로 (1970년대)
1960년대에 약속한 만큼의 성과가 나오지 않자 AI 전체에 대한 실망이 퍼졌다. 영국의 Lighthill 보고서(1973) 이후 연구비가 크게 줄었고, 이 시기를 첫 번째 “AI 겨울”이라고 부른다.

- 기호주의의 방향 전환 : 모든 것을 아는 AI 대신, 의학이나 화학처럼 좁은 분야의 전문가 지식만 규칙으로 옮겼다. 이것이 전문가 시스템이다(예: 혈액 감염 진단 MYCIN).
- 연결주의의 상황 : 연구는 거의 멈췄지만 역전파의 씨앗이 뿌려졌다. 1970년 Linnainmaa가 미분을 거꾸로 계산하는 방법을, 1974년 Werbos가 이를 신경망 학습에 쓰자는 제안을 냈다. 다만 거의 주목받지 못했다.
- 당시의 판단 : "모든 것을 아는 AI는 어렵지만, 좁은 분야의 지식은 규칙으로 옮길 수 있다." → 기호주의가 전문가 시스템으로 다시 일어섰다.

---

### 4. 규칙은 감당할 수 없고, 신경망은 층을 쌓는 법을 찾는다 → 기호주의의 몰락과 연결주의의 부활 (1980년대)
1980년대 초 전문가 시스템이 기업으로 퍼지며 기호주의는 전성기를 맞았다(예: 컴퓨터 부품 구성 XCON, 1980). 그러나 10년이 채 안 되어 무너졌고, 그 빈자리에서 연결주의가 다시 살아났다.

- 기호주의의 한계 : 규칙이 수천 개로 늘자 서로 충돌했고, 세상이 바뀔 때마다 사람이 다시 써야 했다. 규칙을 만들고 유지하는 비용(지식 획득 병목)을 감당할 수 없었다.
- 결과 : 1980년대 말 전문가 시스템 시장이 무너지며 두 번째 AI 겨울이 왔다.
- 막혀 있던 문제 : 입력과 출력 사이에 층(은닉층)을 넣으면 XOR도 풀린다. 하지만 은닉층에는 정답이 없어서 그 가중치를 어떻게 고칠지 몰랐다.
- 연결주의의 돌파 : 1986년 Rumelhart/Hinton/Williams가 역전파를 널리 알렸다. 출력의 오차를 거꾸로 전달하며 각 가중치의 책임(기울기)을 계산하고, 오차가 줄어드는 방향으로 가중치를 옮긴다(경사 하강법). 이로써 층을 쌓은 신경망을 학습할 수 있게 되었다.

---

### 5. 신경망은 다루기 어렵다 → 통계적 학습으로 이동 (1990년대\~2011)
가장 헷갈리는 시기다. 역전파가 생겼으니 신경망이 앞서 나갔을 것 같지만, 실제로 주류가 된 것은 SVM 같은 통계적 학습이었다.

- 배경 : 데이터는 수천\~수만 개였고, 컴퓨터는 여전히 느렸다.
- 이 환경에서 신경망의 약점 :
  - 과대적합 : 파라미터가 많아 적은 데이터를 외워 버렸다.
  - 기울기 소실 : 층이 깊으면 앞쪽 층까지 기울기가 전달되지 않았다. 그래서 1\~2층짜리 얕은 망만 쓸 수 있었다.
  - 불안정 : 근처 웅덩이에 갇히거나(지역 최솟값) 같은 설정으로도 결과가 매번 달랐다. 사람이 정할 값(하이퍼파라미터)도 많았다.
- SVM의 등장 : 두 부류를 나누는 경계 중 양쪽 데이터와 가장 멀리 떨어진 경계를 고른다(이 거리가 마진). 직선으로 안 나뉘면 커널로 곡선 경계를 만든다(Boser/Guyon/Vapnik 1992, Cortes/Vapnik 1995).
- SVM의 강점 : 표준 SVM은 볼록 최적화 문제이므로, 더 나쁜 지역 최솟값에 갇히는 문제를 피할 수 있다. 다만 볼록하다는 사실만으로 해가 항상 하나인 것은 아니다. 적절한 특징이 있으면 비교적 적은 데이터에서도 강력하며, RBF 커널 SVM에서는 C와 γ가 대표적인 조정값이다. 커널 종류나 다른 설정도 선택해야 한다.
- SVM의 약점이 견딜 만했던 이유 : 특징은 사람이 설계해야 했지만(특징 공학), 데이터가 적으니 전문가가 직접 만들 수 있었다.
- 당시의 판단 : "특징 설계의 수고" 대 "학습의 안정성"을 놓고 안정성이 이겼다. → 연구와 실무가 통계적 학습으로 옮겨갔다. 같은 시기 앙상블(AdaBoost 1995, 랜덤 포레스트 2001)도 발전했다.
- 참고 : 신경망이 버려진 것은 아니다. CNN(1989)과 LSTM(1997)이 이 시기에 나왔지만 소수였다.

---

### 6. 특징을 사람이 만드는 한계 → 딥러닝의 귀환 (2006\~2012)
2000년대 후반 데이터와 계산 환경이 바뀌자, 통계적 학습의 약점과 신경망의 약점이 자리를 바꿨다.

- 환경 변화 : 인터넷으로 데이터가 폭증했고, ImageNet(2009)은 라벨 붙은 이미지 100만 장 이상을 제공했다. 2007년 CUDA로 GPU(수천 개의 계산을 동시에 처리하는 장치)를 일반 계산에 쓸 수 있게 되며 신경망 학습이 수십 배 빨라졌다.
- SVM의 약점이 치명적으로 바뀜 : 수백만 개 데이터의 특징을 사람이 설계할 수 없었고, 커널 SVM은 계산량이 데이터 수의 제곱으로 늘어 감당하지 못했다.
- 신경망의 약점이 해결됨 : 데이터가 많아 과대적합이 줄고, GPU가 계산 부족을 풀었다. 2006년 Hinton이 깊은 망도 학습될 수 있음을 보이며 "딥러닝"이라는 이름이 쓰이기 시작했고, ReLU(2010), Dropout(2012), Adam(2014), 배치 정규화(2015) 같은 학습 요령이 뒤따랐다.
- 핵심 아이디어 : 은닉층의 "새 특징 만들기"를 여러 단계로 쌓는다. 앞쪽 층은 선과 모서리를, 뒤쪽 층은 눈/귀/얼굴 같은 복잡한 패턴을 배우므로 사람이 특징을 설계할 필요가 없다.
- 결정적 사건 : 2012년 AlexNet이 이미지 인식 대회에서 사람이 설계한 특징 기반 방법을 큰 차이로 이겼다.
- 당시의 판단 : "설명 가능성과 안정성" 대 "정확도와 확장성"을 놓고 정확도와 확장성이 이겼다. → 연구자들이 몇 년 안에 대거 신경망으로 옮겨갔다.

---

### 7. 순서가 있는 데이터는 느리고 잊는다 → 어텐션과 Transformer (2014\~)
딥러닝이 이미지에서 성공한 뒤에도, 문장이나 로그처럼 순서가 있는 데이터는 숙제로 남았다. 이 숙제를 푼 것이 Transformer이고, 그 위에서 오늘날의 LLM이 나왔다.

- 남은 문제 :
  - RNN(1990, 앞 단계의 기억을 넘기며 한 단어씩 읽는 신경망)은 문장이 길면 앞 내용을 잊었다. LSTM(1997)이 기억을 남기고 지우는 문(게이트)으로 완화했지만, 한 단계씩 읽어야 해서 GPU를 제대로 쓰지 못했다.
  - 번역 모델(Seq2seq, 2014)은 문장 전체를 벡터 하나로 압축해 넘겨서, 긴 문장을 다 담지 못했다.
  - 라벨 붙은 데이터는 여전히 비쌌다.
- 돌파 :
  - 어텐션(Bahdanau 외, 2014) : 단어를 하나 만들 때마다 입력 전체를 다시 보고 필요한 부분에 집중한다.
  - Transformer(Vaswani 외, 2017) : RNN 구조를 버리고 어텐션만 남겼다. 모든 단어가 서로를 한꺼번에 보므로(셀프 어텐션) 병렬 계산이 가능하다.
  - 자기지도 학습 : "다음 단어 맞히기"처럼 데이터 자체에서 정답을 만들어, 라벨 없는 인터넷 텍스트 전체를 학습 재료로 쓴다.
- 결과 : 모델과 데이터를 키울수록 성능이 오르는 구조가 만들어졌다. GPT(2018)를 시작으로 GPT-3(2020, 파라미터 1,750억 개)처럼 모델이 거대해졌고, 이것이 오늘날의 대규모 언어 모델(LLM)이다.

## 정리

| 단계 | 시기 | 환경 | 주류 | 결정적 이유 |
| --- | --- | --- | --- | --- |
| 1 | 1950\~1960년대 | 데이터/계산 극소 | 기호주의 | 규칙이 분명한 문제에서 빠르게 성과를 냄 |
| 2 | 1958\~1969 | 데이터/계산 극소 | 기호주의 (퍼셉트론 좌절) | 신경망은 직선 하나뿐이었고, 층을 학습시킬 방법이 없었음 |
| 3 | 1970년대 | AI에 대한 실망, 연구비 축소 (첫 번째 AI 겨울) | 기호주의 (전문가 시스템) | 좁은 분야에 규칙을 집중하니 실용적 성과가 났음 |
| 4 | 1980년대 | 전문가 시스템 확산, 규칙 유지 비용 폭발 | 기호주의 몰락 (두 번째 AI 겨울), 연결주의 부활 | 규칙을 사람이 계속 쓸 수 없었음. 역전파로 은닉층을 학습할 수 있게 됨 |
| 5 | 1990년대\~2011 | 데이터 적음, CPU 느림 | 통계적 학습 | 적은 데이터에서 안정적이었고, 특징 설계 수고는 감당 가능했음 |
| 6 | 2006\~2012 | 데이터 폭증, GPU | 연결주의 (딥러닝) | 특징 설계가 불가능해졌고, 신경망의 약점이 해결됨 |
| 7 | 2014\~ | 인터넷 규모의 텍스트, 대규모 GPU 병렬 계산 | 연결주의 (Transformer, LLM) | 병렬 계산과 자기지도 학습으로 규모를 키울 수 있게 됨 |
