## 서론

**신경망은 가중치를 고칠 방향을 어떻게 알아낼까**

신경망의 학습을 간단히 설명하면, 예측과 정답의 차이를 구한 다음 그 차이가 줄어들도록 가중치를 고치는 과정이다. 앞서 살펴본 경사 하강법, 모멘텀, Adam도 모두 이 과정에서 가중치를 어떻게 움직일지 정하는 방법이었다.

그런데 가중치를 고치려면 먼저 알아야 하는 것이 있다.

지금 이 가중치를 조금 바꾸면, 최종 손실은 어느 방향으로 얼마나 달라지는가?

선형 회귀처럼 식이 짧으면 직접 미분해서 알아낼 수 있다. 하지만 신경망에는 수많은 가중치가 있고, 곱셈과 덧셈, 활성화 함수가 여러 층에 걸쳐 연결되어 있다. 모델을 바꿀 때마다 전체 식을 사람이 다시 미분해서 코드로 작성하기는 어렵다.

이 문제를 해결하려면 컴퓨터가 계산 과정을 기억하고, 각 계산이 최종 손실에 미친 영향을 스스로 구할 수 있어야 한다.

그 계산 과정을 연결해 놓은 것이 계산 그래프(computation graph)이다. 그리고 기록된 계산에 미분 규칙을 적용해 기울기를 구하는 기능이 자동 미분(automatic defferentiation)이다.

계산 그래프와 자동 미분을 이해하면, 학습 코드에 들어가는 loss.backward() 한 줄이 무엇을 하는지 구체적으로 볼 수 있다.

## 1. 신경망의 학습 과정에서 미분이 들어가는 자리

먼저 전체 학습 과정을 펼쳐보자.

신경망을 만들 때는 어떤 층을 사용할지, 층 사이에 어떤 함수를 넣을지 정한다. 예를 들어 입력을 Dense 층에 넣고, ReLU를 적용하고, 다른 Dense 층을 거쳐 Softmax로 클래스별 확률을 만들 수 있다.

여기서 Dense는 앞 층의 값들을 가중치로 조합하는 층이다. 기본 계산은 다음과 같다.

![계산 그래프 - 10장 — 1번 그림](/images/ai-study/313c53d0edcbefaf9e79.png)

각 기호의 의미는 다음과 같다.

```txt
• x: 입력값을 모은 벡터이다.
• W: 입력마다 곱할 가중치를 모은 행렬이다.
• b: 결과에 더하는 편향이다.
• z: 가중합으로 계산한 결과이다.
```

벡터는 숫자를 한 줄로 모은 것이고, 행렬은 숫자를 표처럼 모은 것이다. 딥러닝에서는 숫자 하나부터 여러 차원으로 배열된 숫자 묶음까지 텐서(tensor)라는 말로 다룬다.

각 구성 요소는 다음 역할을 맡는다.

| 구성 요소 | 하는 일 |
| --- | --- |
| Dense | 입력에 가중치를 곱하고 더해 새로운 값을 만든다. |
| ReLU | 음수는 0으로 바꾸고, 양수는 그대로 통과시킨다. |
| Softmax | 클래스별 점수를 합이 1인 확률로 바꾼다. |
| 손실 함수 | 예측과 정답이 얼마나 다른지 숫자로 나타낸다. |
| 옵티마이저 | 계산된 기울기를 이용해 가중치를 갱신한다. |

모델을 정하고 손실 함수와 옵티마이저까지 정하면, 학습 데이터를 넣어 다음 과정을 반복한다.

| 단계 | 계산하는 내용 |
| --- | --- |
| 순전파 | 입력부터 출력을 향해 계산하여 예측을 만든다. |
| 손실 계산 | 예측과 정답을 비교한다. |
| 역전파 | 손실에 대한 각 가중치의 기울기를 구한다. |
| 가중치 갱신 | 기울기를 이용해 가중치를 바꾼다. |

순전파(forward pass)는 값을 계산하는 과정이다. 입력에 가중치를 곱하고, 활성화 함수를 적용하고, 다음 층으로 전달하면서 최종 예측을 만든다.

예측이 나왔다고 학습이 끝난 것은 아니다. 정답과 비교해 얼마나 틀렸는지 측정해야 한다. 숫자를 예측하는 회귀 문제에서는 MSE를, 클래스를 구분하는 분류 문제에서는 교차 엔트로피 같은 손실 함수를 사용할 수 있다.

그다음 역전파(backward pass)에서 각 가중치가 손실에 미친 영향을 구한다. 마지막으로 옵티마이저가 그 결과를 받아 가중치를 바꾼다.

PyTorch에서는 이 과정을 다음처럼 작성한다.

```py
optimizer.zero_grad()

outputs = model(inputs)
loss = loss_fn(outputs, labels)

loss.backward()
optimizer.step()
```

코드와 학습 과정은 다음과 대응한다.

- optimizer.zero\_grad() : 이전 계산에서 남은 기울기를 비운다.

- model(inputs) : 순전파를 실행한다.

- loss\_fn(outputs, labels) : 예측과 정답으로 손실을 계산한다.

- loss.backward()**:** 손실을 기준으로 기울기를 계산한다.

- optimizer.step()**:** 기울기를 이용해 가중치를 바꾼다.

여기서 backward()와 step()의 역할을 구분해야 한다.

backward()는 기울기를 계산한다. 가중치를 실제로 바꾸는 것은 step()이다.

Keras의 model.fit(…)은 이런 학습 반복을 내부에서 관리해 주는 메서드이다. 데이터를 작은 묶음으로 나누고, 각 묶음에 대해 학습을 수행하며, 정한 횟수만큼 전체 데이터를 반복해서 사용한다. 직접 반복문을 작성하든 fit()을 사용하든 학습의 기본 구조는 같다.

이제 그중에서 가장 중요한 계산인 기울기를 살펴보자.

## 2. 미분은 입력 변화가 결과에 미치는 영향을 나타낸다.

미분을 이해할 때는 먼저 “무엇을 바꿨을 때 무엇이 달라지는가”를 정하면 좋다.

예를 들어 사과 한 개 가격이 100원이고 두 개를 산다고 하자. 사과 한 개 가격이 1원 오르면 두 개 가격은 2원 오른다. 여기에 소비세 10%가 붙으면 최종 결제 금액은 2.2원 오른다.

즉, 사과 한 개 가격의 변화가 최종 금액에 2.2배로 반영된다.

미분은 이처럼 입력을 조금 바꿨을 때 결과가 얼마나 바뀌는지를 나타낸다.

함수 f(x)의 미분은 다음과 같이 정의한다.

![계산 그래프 - 10장 — 2번 그림](/images/ai-study/be7b7ff33429b6536b38.png)

식의 각 부분을 풀어 보면 다음과 같다.

- **h :** 입력을 바꾼 양이다.
- **f(x+h) − f(x) :** 입력 변화 때문에 결과가 바뀐 양이다.
- **둘을 나눈 값:** 입력 변화량에 대한 결과 변화량의 비율이다.
- **h → 0 :** 입력 변화량을 한없이 작게 줄여 해당 지점의 변화율을 구한다는 뜻이다.

신경망에서는 입력 대신 가중치를 바꿔 본다.

가중치를 아주 조금 바꾸면 손실이 얼마나 달라지는가?

가중치 w에 대한 손실 L의 미분은 다음처럼 쓴다.

![계산 그래프 - 10장 — 3번 그림](/images/ai-study/53cbb470d282368c7e39.png)

∂는 변수가 여러 개 있을 때, 다른 변수는 고정하고 특정 변수 하나에 대해서만 미분한다는 표시이다. 이를 **편미분**이라고 한다. ∂L/∂w는 “가중치 w를 조금 바꿨을 때 손실 L이 얼마나 달라지는가”를 나타낸다.

신경망에는 가중치가 많으므로 가중치마다 편미분을 구해야 한다. 이 편미분들을 한데 모은 것이 **기울기(gradient)이다**. ∇L은 손실의 기울기를 뜻한다.

![계산 그래프 - 10장 — 4번 그림](/images/ai-study/9b456b8833391fed0989.png)

각 칸에는 가중치 하나에 대한 손실의 편미분이 들어간다. 어떤 가중치를 바꿨을 때 손실이 얼마나 달라지는지, 가중치별로 기록한 목록이라고 이해할 수 있다.

기울기의 부호를 보면 가중치를 어느 방향으로 움직일지 알 수 있다.

- **기울기가 양수이면:** 가중치를 조금 키울 때 손실도 커지는 방향이다. 손실을 줄이려면 가중치를 줄인다.
- **기울기가 음수이면:** 가중치를 조금 키울 때 손실이 작아지는 방향이다. 손실을 줄이려면 가중치를 키운다.

그래서 경사 하강법은 다음 식을 사용한다.

![계산 그래프 - 10장 — 5번 그림](/images/ai-study/ec04b90d47fc61d27db4.png)

η는 학습률이다. 기울기가 알려 준 방향으로 얼마나 움직일지 정한다. 옵티마이저는 이 갱신 방법을 정하는 도구이고, 계산 그래프와 자동 미분은 갱신에 필요한 기울기를 구하는 일을 맡는다.

## 3. 컴퓨터로 미분을 구하는 세 가지 방법

미분을 컴퓨터로 계산하는 방법에는 수치 미분, 기호 미분, 자동 미분이 있다. 세 방법은 무엇을 계산하는지부터 다르다.

### 수치 미분은 입력을 조금 바꿔 결과를 비교한다

미분의 정의에서 h를 아주 작은 숫자로 정하면 변화율을 대략 계산할 수 있다. 예를 들어 f(x) = x²이고 x = 3, h = 0.001이면 다음과 같다.

![계산 그래프 - 10장 — 6번 그림](/images/ai-study/03667193e56dec5b8eb6.png)

실제 미분값은 2x = 6이므로 가까운 값을 얻었다. 이것이 **수치 미분**이다. 식의 구조를 몰라도 함수를 실행할 수 있으면 결과를 비교해 미분을 근사할 수 있다.

하지만 신경망에서는 비용이 커진다. 가중치를 하나씩 바꿔 가며 손실을 다시 계산해야 하기 때문이다. 가중치가 많을수록 모델 전체를 반복해서 실행하는 횟수도 늘어난다.

정확도에도 문제가 있다. h가 너무 크면 실제 순간 변화율과 차이가 커지고, 너무 작으면 매우 비슷한 두 숫자를 빼는 과정에서 컴퓨터의 제한된 숫자 정밀도가 문제가 될 수 있다.

수치 미분은 큰 신경망을 학습시키는 주된 방법보다는, 다른 방식으로 구한 미분값이 맞는지 점검하는 용도로 유용하다.

### 기호 미분은 수식을 다른 수식으로 바꾼다

기호 미분은 사람이 미분 공식을 적용하는 방식과 가깝다. f(x) = x²라는 식을 받아 f′(x) = 2x라는 식을 만든다. 입력도 수식이고 결과도 수식이다.

간단한 식에서는 명확하지만, 식이 복잡해지면 미분 결과가 길어지고 같은 계산이 여러 번 나타날 수 있다. 조건문과 반복문이 들어 있는 프로그램 전체를 수식으로 다루는 일도 쉽지 않다.

### 자동 미분은 실행된 연산들의 미분을 연결한다

자동 미분은 복잡한 계산을 작은 연산으로 나눈다. 예를 들어 다음 계산은 덧셈과 제곱으로 분리할 수 있다.

![계산 그래프 - 10장 — 7번 그림](/images/ai-study/4281b56873def01c7005.png)

덧셈의 미분과 제곱의 미분을 알고 있다면, 두 미분을 연결해서 전체 미분을 구할 수 있다. 자동 미분은 프로그램이 실제로 수행한 연산과 중간값을 이용한다. 각 연산에 준비된 미분 규칙을 적용하고, 그 결과를 연결한다.

| 방법 | 기본 방식 | 주요 특징 |
| --- | --- | --- |
| 수치 미분 | 입력을 조금 바꾸고 결과 차이를 측정한다. | 근삿값을 구하며, 변수가 많으면 계산량이 커진다. |
| 기호 미분 | 미분 규칙으로 새로운 수식을 만든다. | 복잡한 식에서는 결과가 커지거나 계산이 중복될 수 있다. |
| 자동 미분 | 실행된 연산별 미분을 연결한다. | 중간 계산을 재사용하며 많은 변수의 기울기를 효율적으로 구할 수 있다. |

자동 미분이 정확하다는 말은 수치 미분처럼 작은 변화량으로 미분을 근사하지 않고, 미분 규칙을 직접 적용한다는 뜻이다. 컴퓨터의 반올림 오차까지 사라진다는 의미는 아니다.

### 자동 미분에는 두 가지 진행 방향이 있다

자동 미분은 크게 Forward mode와 Reverse mode로 나뉜다.

- **Forward mode:** 특정 입력을 바꿨을 때의 영향을 계산 진행 방향으로 전달한다.
- **Reverse mode:** 특정 출력에서 출발해 각 입력이 그 출력에 미친 영향을 거꾸로 계산한다.

신경망에는 가중치가 아주 많지만, 학습에 사용하는 최종 손실은 보통 숫자 하나이다. 따라서 손실 하나에서 출발해 많은 가중치의 기울기를 구하는 Reverse mode가 잘 맞는다.

여기서 **순전파와 Forward mode를 같은 말로 보면 안 된다.** Reverse mode 자동 미분도 먼저 순전파를 실행해 중간값과 최종 결과를 구한다. 이후 미분 계산을 거꾸로 수행한다.

그렇다면 컴퓨터는 어떤 연산들을 거꾸로 따라가야 하는지 어떻게 알까? 이를 위해 계산의 연결 관계를 기록해야 한다.

## 4. 계산 그래프는 연산과 데이터의 연결 관계를 기록한다

계산 그래프에서 그래프는 막대그래프나 꺾은선그래프를 뜻하지 않는다. 점과 연결선으로 관계를 나타내는 구조라는 뜻이다.

- **노드(node):** 덧셈, 곱셈, 활성화 함수 같은 연산이다.
- **엣지(edge):** 연산 사이에서 값이 전달되는 연결선이다.

예를 들어 z = Wx + b에는 가중치를 곱하는 연산과 편향을 더하는 연산이 들어 있다. 그 결과에 ReLU를 적용하면 ReLU 노드가 이어진다. 이후 다른 층과 손실 함수도 같은 방식으로 연결된다.

계산 그래프에는 결국 **어떤 값으로 어떤 연산을 수행했고, 그 결과를 어디에 사용했는지**가 담긴다. 신경망의 연결선에서는 숫자 하나뿐 아니라 벡터와 행렬 같은 텐서도 전달된다.

이 구조는 순전파와 역전파에서 각각 사용된다. 순전파에서는 앞쪽 입력으로부터 계산을 진행해 결과를 만든다. 역전파에서는 최종 결과에서 출발해 연결 관계를 거꾸로 따라간다.

각 노드는 전체 신경망의 식을 알 필요가 없다. 자신이 담당한 연산의 미분 규칙만 알면 된다. 덧셈 노드는 덧셈의 규칙을 적용하고, 곱셈 노드는 곱셈의 규칙을 적용한다. **복잡한 전체 계산을 간단한 부분 계산으로 나눌 수 있다는 점**이 자동 미분을 가능하게 한다.

### 계산 그래프를 만드는 시점은 실행 방식에 따라 다르다

계산 구조를 먼저 정의한 뒤 실행하는 방식을 Define-and-Run, 실행하면서 계산 구조를 만드는 방식을 Define-by-Run이라고 한다.

| 구분 | Define-and-Run | Define-by-Run |
| --- | --- | --- |
| 기본 방식 | 계산 그래프를 먼저 구성한 뒤 실행한다. | 실제 연산을 실행하면서 계산 그래프를 만든다. |
| 흔히 쓰는 표현 | 정적 계산 그래프 | 동적 계산 그래프 |
| 장점 | 전체 구조를 미리 분석하고 최적화하기 좋다. | 코드 실행 흐름과 가까워 유연하고 오류를 추적하기 쉽다. |
| 고려할 점 | 구조 정의와 실행이 나뉘어 오류 추적이 복잡할 수 있다. | 실행 중 구조를 기록하므로 최적화가 더 복잡할 수 있다. |
| 대표 사례 | TensorFlow 1.x의 전통적인 실행 방식 | PyTorch의 일반적인 실행 방식, TensorFlow 2의 즉시 실행 |

동적 방식에서는 입력에 따라 if나 for의 실행 경로가 달라지더라도 실제로 수행된 연산을 따라 그래프를 구성할 수 있다. 모델 코드를 작성하는 것만으로 모든 프레임워크에서 정적 계산 그래프가 만들어지는 것은 아니다.

정적 방식이면 언제나 빠르고 동적 방식이면 언제나 느리다고 단정할 수도 없다. 실제 속도는 연산의 종류, 모델 크기, 최적화 방식에 따라 달라진다. 하나의 프레임워크가 두 방식의 장점을 함께 활용하기도 한다. TensorFlow 2는 기본적으로 연산을 즉시 실행하지만, tf.function을 사용해 함수의 계산을 그래프로 만들 수 있다. [TensorFlow 실행 방식 문서](https://www.tensorflow.org/guide/function)

실행 방식이 달라져도 계산 그래프를 사용하는 목적은 같다. 연산의 연결 관계를 파악하고, 이를 이용해 값을 계산하거나 미분하는 것이다. 이제 작은 계산 하나를 그래프로 읽어 보자.

## 5. 사과 가격으로 순전파와 역전파를 이해하기

사과 한 개가 100원이고 두 개를 샀다고 하자. 소비세 10%가 붙을 때 최종 결제 금액을 구해 보자.

![계산 그래프 - 10장 — 8번 그림](/images/ai-study/90c3780451db5f547f39.png)

원 안의 ×는 곱셈을 뜻한다. 선 위의 숫자는 각 계산에 사용되는 값이나 계산 결과이다. 먼저 100 × 2 = 200으로 세전 금액을 구한다. 소비세 10%가 붙으면 원래 금액의 110%를 내므로 200 × 1.1 = 220이 된다. 최종 결제 금액은 220원이다.

이처럼 입력값을 받아 계산 순서대로 결과를 구하는 것이 순전파이다. 변수로 표현하면 a = pn, C = at이다.

- **p:** 사과 한 개 가격이다.
- **n:** 사과 개수이다.
- **t:** 세금을 포함한 배율이다. 여기서는 1.1이다.
- **a:** 세전 금액이다.
- **C:** 최종 결제 금액이다.

이제 사과 한 개 가격이 1원 오르면 최종 금액은 얼마나 오르는지 생각해 보자. 두 개를 샀으므로 세전 금액은 2원 오른다. 여기에 세금이 붙으므로 최종 금액은 2.2원 오른다. 즉, ∂C/∂p = 2 × 1.1 = 2.2이다.

순전파로 구한 220은 실제 결제 금액이다. 미분으로 구한 2.2는 가격 변화가 결제 금액에 반영되는 비율이다. 두 숫자는 역할이 다르다.

여기서 전체 변화율을 구할 때 중간 단계의 변화율을 곱했다. 가격 변화가 세전 금액에 미치는 영향과, 세전 금액 변화가 최종 금액에 미치는 영향을 연결한 것이다. 이 규칙이 연쇄 법칙이다.

## 6. 연쇄 법칙은 중간 단계의 변화율들을 연결한다

어떤 계산이 중간값을 거쳐 최종 결과를 만든다고 하자. t = g(x)로 중간값을 만들고, y = f(t)로 최종 결과를 계산한다. 입력 x가 바뀌면 먼저 t가 바뀐다. 그리고 t가 바뀌면서 y가 바뀐다.

![계산 그래프 - 10장 — 9번 그림](/images/ai-study/fd7b5a5f056cc825a0bf.png)

이것이 **연쇄 법칙(chain rule)이다**. 마지막 줄은 같은 규칙을 합성함수 표기로 쓴 것이다.

- **dt/dx:** 입력 x의 변화가 중간값 t에 반영되는 정도이다.
- **dy/dt:** 중간값 t의 변화가 결과 y에 반영되는 정도이다.
- **두 값을 곱한 결과:** 입력 x의 변화가 최종 결과 y에 반영되는 정도이다.

### 덧셈 뒤에 제곱이 붙은 계산

전체 식이 z = (x + y)²이라고 하자. t = x + y와 z = t²로 나누면 덧셈과 제곱 두 연산이 된다.

![계산 그래프 - 10장 — 10번 그림](/images/ai-study/23baa5531de2e8a103db.png)

가는 선은 값이 계산되는 방향이고, 굵은 선은 기울기가 전달되는 방향이다. `**2`는 제곱 연산을 뜻한다. x에 대한 z의 미분은 다음처럼 두 연산의 미분을 연결해 구한다.

![계산 그래프 - 10장 — 11번 그림](/images/ai-study/fbc8543df56b2ace8441.png)

제곱 연산의 미분은 2t이고, 덧셈에서 x에 대한 미분은 1이다. 두 값을 곱하면 2(x + y)가 된다.

역전파가 최종 결과에서 1로 시작하는 이유도 설명할 수 있다.

![계산 그래프 - 10장 — 12번 그림](/images/ai-study/f84e30b224daf1a9ff0f.png)

결과 z가 자기 자신에 미치는 변화율은 1이다. 이 값에서 시작해 각 연산의 미분을 곱하며 앞쪽으로 이동한다.

예를 들어 x = 2, y = 3이면 t = 5, z = 25이다. 이 지점에서 x에 대한 기울기는 2 × 5 = 10이다. 따라서 x를 아주 조금 증가시키면 z는 그 변화량의 약 10배만큼 증가한다.

각 노드는 자신의 미분만 처리했다. 제곱 노드는 2t를 곱했고, 덧셈 노드는 1을 곱했다. 자동 미분은 이 원리를 더 긴 계산에도 적용한다.

## 7. 덧셈과 곱셈 노드의 역전파

역전파를 계산할 때는 두 종류의 미분을 구분해야 한다. 하나는 **현재 연산 자체의 미분**이고, 다른 하나는 **뒤쪽 계산에서 이미 구해져 전달된 기울기**이다.

현재 노드의 출력이 z, 최종 손실이 L이면 뒤에서 전달되는 값은 ∂L/∂z이다. 현재 출력 z가 변할 때 최종 손실 L이 얼마나 변하는지를 나타낸다. 현재 노드는 이 값에 자신의 미분을 곱해 앞쪽으로 전달한다.

![계산 그래프 - 10장 — 13번 그림](/images/ai-study/45ad1071d607721fa642.png)

오른쪽 첫 번째 항은 뒤에서 받은 기울기이고, 두 번째 항은 현재 연산 자체의 미분이다. 두 값을 곱하는 것이 각 노드가 수행하는 기본 작업이다. 손실 L 자체를 거꾸로 보내는 것이 아니라, 손실의 변화율을 전달하는 것이다.

### 덧셈은 기울기를 그대로 전달한다

z = x + y에서 x를 1만큼 늘리면 z도 1만큼 늘어난다. y도 마찬가지이다. 각 입력에 대한 미분이 1이므로 뒤에서 받은 기울기에 각각 1을 곱한다.

![계산 그래프 - 10장 — 14번 그림](/images/ai-study/bfc6c278ae5dec238cf2.png)

![계산 그래프 - 10장 — 15번 그림](/images/ai-study/555b454ab48a435a8c36.png)

왼쪽은 덧셈으로 값을 계산하는 과정이고, 오른쪽은 받은 기울기를 각 입력에 전달하는 과정이다. 순전파 입력이 10과 5라면 출력은 15이다. 이후 뒤에서 기울기 1.3을 받았다면 두 입력 쪽에 각각 1.3을 전달한다.

여기서 1.3을 반씩 나누지 않는다. 각 입력이 출력에 미치는 변화율이 각각 1이기 때문이다.

### 곱셈은 상대편 입력값을 곱해 전달한다

z = xy에서 x를 조금 바꿨을 때 z가 얼마나 바뀌는지는 y에 달려 있다. 반대로 y의 변화가 미치는 영향은 x에 달려 있다.

![계산 그래프 - 10장 — 16번 그림](/images/ai-study/d4a67819024d95029c95.png)

![계산 그래프 - 10장 — 17번 그림](/images/ai-study/2f9f8e1693e04bc1189d.png)

x 쪽으로는 y를 곱하고, y 쪽으로는 x를 곱한다. 입력이 10과 5이고 뒤에서 받은 기울기가 1.3이라면 다음과 같다.

| 계산 대상 | 계산 | 결과 |
| --- | --- | --- |
| 순전파 출력 | 10 × 5 | 50 |
| 입력 10에 대한 기울기 | 1.3 × 5 | 6.5 |
| 입력 5에 대한 기울기 | 1.3 × 10 | 13 |

곱셈 노드의 역전파에는 순전파 때 사용한 입력값이 필요하다. 그래서 입력값을 저장해 두어야 한다. 학습 중 순전파는 예측값을 만드는 동시에 **나중의 역전파에 필요한 정보도 보관한다.**

## 8. 사과 계산을 역전파하면 여러 입력의 영향을 함께 구할 수 있다

앞서 계산한 사과 예제는 a = pn, C = at였다. 현재 값은 p = 100, n = 2, t = 1.1, a = 200, C = 220이다.

![계산 그래프 - 10장 — 18번 그림](/images/ai-study/7de8284a134bfe003026.png)

가는 선 쪽에는 순전파 값이, 굵은 선 쪽에는 역전파로 계산한 기울기가 적혀 있다. 최종 결과에서 1로 시작한 뒤, 마지막 곱셈 C = at에서 상대편 입력을 곱한다.

![계산 그래프 - 10장 — 19번 그림](/images/ai-study/5494b7496c64ddb8387b.png)

이제 앞의 곱셈 a = pn에 기울기 1.1이 전달된다. 여기에서도 상대편 입력을 곱한다.

![계산 그래프 - 10장 — 20번 그림](/images/ai-study/6a1698625c82e0847b2c.png)

| 입력 | 미분값 | 의미 |
| --- | --- | --- |
| 사과 한 개 가격 p | 2.2 | 가격이 1원 오르면 최종 금액이 2.2원 오른다. |
| 사과 개수 n | 110 | 한 개를 더 사면 최종 금액이 110원 늘어난다. |
| 세금 포함 배율 t | 200 | 배율이 0.01 늘어나면 최종 금액이 2원 늘어난다. |

세금 부분은 입력의 단위를 구분해야 한다. 그래프에 들어가는 값은 세율 10이라는 숫자가 아니라 세금을 포함한 배율 1.1이다. 세율이 10%에서 11%가 되면 배율은 1.10에서 1.11로 바뀐다. 변화량이 0.01이므로 최종 금액은 200 × 0.01 = 2원 늘어난다.

개수는 현실에서 정수이지만 식에서는 연속적으로 변하는 변수처럼 미분했다. 이 식은 개수에 대해 선형이므로 한 개를 추가할 때의 실제 금액 차이도 110원으로 일치한다.

가격, 개수, 세금에 대한 미분을 각각 처음부터 계산하지 않았다. 뒤쪽에서 구한 기울기 1.1을 앞쪽의 두 계산이 공유했다. 신경망에서도 같은 방식으로 중간 계산을 재사용한다. 손실 하나에서 시작한 역전파로 많은 가중치의 기울기를 함께 구할 수 있는 이유이다.

## 9. 활성화 함수도 같은 규칙으로 역전파한다

덧셈과 곱셈을 이해했다면 활성화 함수도 같은 방식으로 다룰 수 있다. 활성화 함수는 가중합을 다른 값으로 바꾸는 함수이다. 역전파에서는 뒤에서 받은 기울기에 활성화 함수의 미분을 곱한다.

### ReLU는 입력 부호에 따라 기울기를 통과시키거나 막는다

ReLU는 양수 구간에서는 입력을 그대로 내보내고, 음수 구간에서는 출력을 0으로 만든다. 양수 구간의 기울기는 1이고 음수 구간의 기울기는 0이므로, 역전파도 다음처럼 나뉜다.

![계산 그래프 - 10장 — 21번 그림](/images/ai-study/0f62b2b87e3ab5324634.png)

![계산 그래프 - 10장 — 22번 그림](/images/ai-study/197dabc8fd9f6c8b99c8.png)

입력이 양수였으면 기울기를 그대로 통과시키고, 0 이하였으면 기울기를 0으로 만든다. 뒤에서 기울기 3을 받았다고 하자.

| 순전파 입력 | 순전파 출력 | 역전파 결과 |
| --- | --- | --- |
| 2 | 2 | 3 × 1 = 3 |
| −2 | 0 | 3 × 0 = 0 |

정확히 x = 0에서는 함수가 꺾이므로 일반적인 미분이 정의되지 않는다. 구현에서는 이 지점에 사용할 값을 정해야 하며, 여기서는 0으로 처리한다.

ReLU가 기울기 소실을 줄이는 이유도 여기서 이해할 수 있다. 양수 구간에서는 활성화 함수의 미분으로 1을 곱하므로, 이 연산 자체가 기울기를 작게 만들지 않는다. 반대로 계속 음수 입력을 받는 뉴런에서는 기울기가 0이 될 수 있다. 해당 경로로 학습 신호가 전달되지 않는 문제와 연결된다.

다만 전체 기울기에는 가중치 행렬 등 다른 연산도 영향을 준다. ReLU의 양수 구간 미분이 1이라는 사실만으로 신경망 전체의 기울기가 항상 유지되는 것은 아니다.

### tanh는 출력값으로 미분을 계산할 수 있다

tanh는 입력을 −1과 1 사이로 바꾸는 S자 모양 함수이다. 출력이 y라면 미분은 1 − y²이다. 역전파에서는 뒤에서 받은 기울기에 이 값을 곱한다.

![계산 그래프 - 10장 — 23번 그림](/images/ai-study/b043ed2ff47961b3abe8.png)

출력이 −1이나 1에 가까우면 y²은 1에 가까워진다. 따라서 1 − y²은 0에 가까워지고 전달되는 기울기도 작아진다. 활성화 함수의 양 끝이 평평해지면 기울기가 약해진다는 설명을 수식으로 확인할 수 있다.

## 10. Sigmoid를 분해하면 미분 공식이 만들어지는 과정이 보인다

Sigmoid는 입력을 0과 1 사이로 바꾸는 함수이다.

![계산 그래프 - 10장 — 24번 그림](/images/ai-study/e86aa9a4f158a2b8fe50.png)

exp(u)는 e의 u제곱을 뜻한다. e는 약 2.718인 수학 상수이다. 식 전체를 한 번에 미분하기보다 작은 연산으로 나눠 보자.

| 단계 | 계산 | 수행하는 연산 |
| --- | --- | --- |
| 1 | a = −x | −1을 곱한다. |
| 2 | b = exp(a) | 지수 함수를 적용한다. |
| 3 | c = 1 + b | 1을 더한다. |
| 4 | y = 1/c | 역수를 구한다. |

역수는 1을 해당 값으로 나눈 것이다.

![계산 그래프 - 10장 — 25번 그림](/images/ai-study/0b5b2300ba6404998fa9.png)

맨 오른쪽의 / 노드는 역수를 계산한다. 이 작은 연산들을 연결하면 Sigmoid가 된다. 이제 뒤에서 전달된 기울기를 G = ∂L/∂y라고 놓고, 오른쪽부터 거꾸로 통과해 보자.

### 역수 노드

y = 1/c를 미분하면 −1/c²이다. 그런데 y = 1/c이므로 −y²으로도 쓸 수 있다. 따라서 뒤에서 받은 기울기 G에 −y²을 곱한다.

![계산 그래프 - 10장 — 26번 그림](/images/ai-study/d3ed1c111d99c3ab5452.png)

### 덧셈 노드

c = 1 + b에서 b에 대한 미분은 1이다. 따라서 받은 기울기를 그대로 전달한다.

![계산 그래프 - 10장 — 27번 그림](/images/ai-study/e6726429fabe208032b1.png)

### 지수 함수 노드

지수 함수는 미분해도 같은 형태이다. b = exp(a)의 미분은 exp(a)이다. 현재 a = −x이므로 다음과 같다.

![계산 그래프 - 10장 — 28번 그림](/images/ai-study/9fb0b3c0a896f6b4bd20.png)

### −1을 곱하는 노드

a = −x의 미분은 −1이다. 앞에서 받은 기울기에 −1을 곱하면 음수 두 개가 곱해져 양수가 된다.

![계산 그래프 - 10장 — 29번 그림](/images/ai-study/f0af5b3baeb4eedef3b0.png)

여기까지가 작은 연산들을 거꾸로 따라가며 얻은 결과이다. 마지막으로 이 결과를 Sigmoid의 출력값 y로 표현하도록 정리해 보자.

### 출력값으로 표현하도록 정리하기

Sigmoid의 정의에서 1 − y를 정리하면 아래 첫 번째 줄을 얻는다. 이 관계를 이용해 y²exp(−x)를 나누어 쓰면 y(1 − y)가 된다.

![계산 그래프 - 10장 — 30번 그림](/images/ai-study/249a13c251083794bb81.png)

결국 Sigmoid의 역전파 식은 다음처럼 정리된다.

![계산 그래프 - 10장 — 31번 그림](/images/ai-study/4c9cf68c61468c2fe846.png)

![계산 그래프 - 10장 — 32번 그림](/images/ai-study/fb46d3b1f9968e4d6552.png)

뒤에서 받은 기울기에 Sigmoid 자체의 미분인 y(1 − y)를 곱한다. **Sigmoid는 순전파 출력 y만 저장해 두면, 역전파에서 자신의 미분을 계산할 수 있다.** 앞에서 나눴던 중간값들을 모두 다시 계산할 필요가 없다.

### 기울기 소실도 이 식에서 확인할 수 있다

| 출력 y | 미분 y(1 − y) |
| --- | --- |
| 0.5 | 0.25 |
| 0.99 | 0.0099 |
| 0.01 | 0.0099 |

미분의 최댓값은 0.25이다. 출력이 0이나 1에 가까워지면 미분은 거의 0이 된다. 역전파에서는 층을 지날 때마다 각 연산의 미분을 곱한다. 작은 값이 여러 번 곱해지면 앞쪽에 도달하는 기울기가 매우 작아질 수 있다.

가중치 초기화나 활성화 함수 선택이 중요한 이유도 여기에 있다. 순전파의 값이 어느 구간에 놓이는지가 역전파의 기울기 크기에 영향을 준다.

## 11. Sigmoid의 순전파와 역전파를 직접 구현하기

앞에서 구한 식을 코드로 옮기면 다음과 같다.

```py
import numpy as np


class Sigmoid:
    def __init__(self):
        self.out = None

    def forward(self, x):
        out = 1 / (1 + np.exp(-x))
        self.out = out
        return out

    def backward(self, dout):
        dx = dout * self.out * (1.0 - self.out)
        return dx
```

forward()는 Sigmoid 출력을 계산하고, 역전파에서 사용할 수 있도록 self.out에 저장한다. backward()는 뒤에서 받은 기울기에 저장해 둔 출력으로 계산한 y(1 − y)를 곱한다.

| 코드 | 의미 |
| --- | --- |
| dout | 뒤에서 전달된 기울기 ∂L/∂y이다. |
| self.out | 순전파에서 계산한 출력 y이다. |
| self.out \* (1.0 - self.out) | Sigmoid 자체의 미분 y(1 − y)이다. |
| dx | 앞쪽으로 전달할 기울기 ∂L/∂x이다. |

입력이 1이고 뒤에서 전달된 기울기가 1인 경우를 계산해 보자.

```py
sigmoid = Sigmoid()

x = np.array([1.0])

y = sigmoid.forward(x)
dx = sigmoid.backward(np.array([1.0]))

print(y)
print(dx)
```

출력은 대략 다음과 같다.

```txt
[0.73105858]
[0.19661193]
```

첫 번째 값은 Sigmoid의 출력이고, 두 번째 값은 입력 1에서의 기울기이다.

![계산 그래프 - 10장 — 33번 그림](/images/ai-study/807652f550b07706e766.png)

만약 뒤에서 전달된 기울기가 2였다면 앞쪽에 전달할 기울기도 두 배가 된다. 2 × 0.19661193 ≈ 0.39322386이다. Sigmoid의 미분만 단독으로 구하는 것과 최종 손실에 대한 기울기를 전달하는 것의 차이가 여기서 드러난다. 실제 역전파에서는 항상 뒤에서 받은 기울기까지 함께 곱해야 한다.

또한 연산마다 저장해야 하는 값이 다르다. 곱셈은 두 입력이 필요했고 Sigmoid는 출력이 필요했다. 프레임워크도 각 연산의 역전파에 필요한 정보를 순전파 중에 보관한다.

## 12. PyTorch의 자동 미분은 같은 계산을 대신 수행한다

PyTorch에서는 Sigmoid의 backward()를 직접 구현하지 않아도 된다.

```py
import torch

x = torch.tensor([1.0], requires_grad=True)
y = torch.sigmoid(x)

y.backward()

print(y)
print(x.grad)
```

requires\_grad=True는 이 텐서에 대해 기울기를 구할 수 있도록 관련 계산을 추적하라는 설정이다. 순전파에서 y는 약 0.7310586이 된다. 그다음 y.backward()를 호출하면 y에서 출발해 x에 대한 미분을 계산한다.

현재 출력은 원소 하나이므로 출력 자신에 대한 미분인 1에서 시작한다. 여기에 Sigmoid의 미분 y(1 − y)를 곱하면 약 0.1966119가 된다. 따라서 x.grad에는 다음 값이 저장된다.

```txt
tensor([0.1966])
```

이 코드는 가중치를 학습시키는 예제가 아니다. 손실 함수와 옵티마이저 없이 **Sigmoid 출력이 입력에 대해 갖는 미분을 자동으로 계산하는 기능**만 확인한다.

실제 학습에서는 최종 손실에 대해 loss.backward()를 호출한다. 그러면 손실에 연결된 연산들을 따라가며 학습 대상 가중치의 기울기를 계산한다. PyTorch에서 이 작업을 담당하는 엔진이 torch.autograd이다. [PyTorch 자동 미분 문서](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)

### 자동 미분이 미분 공식을 새로 만드는 것은 아니다

Sigmoid를 작은 연산으로 나누면 부호 반전, 지수 함수, 덧셈, 역수로 설명할 수 있다.

| 연산 이름 | 의미 |
| --- | --- |
| neg | 부호를 바꾼다. |
| exp | 지수 함수를 계산한다. |
| add | 값을 더한다. |
| reciprocal | 역수를 계산한다. |

이렇게 작은 연산으로 분해하면 연쇄 법칙이 적용되는 과정을 이해하기 좋다. 다만 프레임워크가 torch.sigmoid(x)를 반드시 이 네 개의 노드로 분해해 실행하는 것은 아니다. Sigmoid 자체에 준비된 역전파 규칙을 적용할 수도 있다.

중요한 것은 각 연산에 역전파 방법이 구현되어 있고, 프레임워크가 실제 계산의 연결 관계를 이용해 이를 실행한다는 점이다. [PyTorch Autograd 내부 동작 문서](https://docs.pytorch.org/docs/2.15/notes/autograd.html) “자동”이라는 말은 모델 전체의 미분을 사람이 매번 작성하지 않아도 된다는 뜻이다. 연산의 미분 규칙과 연결 구조를 이용해 필요한 계산을 대신 수행한다.

## 13. 작은 신경망 하나에서 전체 과정을 연결하기

지금까지는 각 연산을 나눠 살펴봤다. 이제 가중합, 활성화 함수, 손실을 연결해 실제로 가중치의 기울기를 구해 보자. 입력 하나를 받는 간단한 모델을 생각한다.

![계산 그래프 - 10장 — 34번 그림](/images/ai-study/e0b38e9bfb7c816ef0c2.png)

z는 가중합이고 r은 ReLU를 통과한 예측값이다. q는 정답이다. 손실 앞의 1/2은 미분할 때 제곱에서 나오는 2를 없애 식을 간단하게 만드는 역할을 한다.

입력 x = 3, 가중치 w = 2, 편향 b = 1, 정답 q = 5를 사용하자.

### 순전파로 예측과 손실을 계산한다

![계산 그래프 - 10장 — 35번 그림](/images/ai-study/ca7989692dd540032e1f.png)

가중합은 7이고 양수이므로 ReLU를 그대로 통과한다. 예측값 7과 정답 5를 비교하면 손실은 2이다. 여기까지가 값을 계산하는 과정이다.

### 손실에서 출발해 기울기를 거꾸로 계산한다

먼저 예측값 r에 대한 손실의 미분을 구하면 r − q = 2이다. ReLU의 입력 z가 양수이므로 미분은 1이다. 이어서 가중합 z = wx + b를 미분하면 w에 대해서는 x = 3, b에 대해서는 1이 나온다.

![계산 그래프 - 10장 — 36번 그림](/images/ai-study/c4c2103183194ed12886.png)

손실이 2라는 사실만으로는 어떤 가중치를 얼마나 고칠지 알 수 없었다. 역전파를 통해 가중치의 기울기 6과 편향의 기울기 2를 구하면서 갱신 방향이 정해졌다.

학습률을 0.1로 설정한 경사 하강법이라면 다음처럼 갱신한다.

![계산 그래프 - 10장 — 37번 그림](/images/ai-study/2ee3372bc4a61941aa3b.png)

### 같은 계산을 자동 미분으로 확인한다

```py
import torch

x = torch.tensor(3.0)

w = torch.tensor(2.0, requires_grad=True)
b = torch.tensor(1.0, requires_grad=True)

target = torch.tensor(5.0)

z = w * x + b
prediction = torch.relu(z)

loss = 0.5 * (prediction - target) ** 2

loss.backward()

print(loss.item())
print(w.grad.item())
print(b.grad.item())
```

각 출력은 손실, 가중치의 기울기, 편향의 기울기에 대응한다.

```txt
2.0
6.0
2.0
```

직접 계산한 손실과 기울기가 그대로 나온다. 이 코드에서 컴퓨터가 따라간 것은 곱셈과 덧셈, ReLU, 제곱의 미분을 연쇄 법칙으로 연결한 과정이다.

신경망이 커지면 이 연산들이 더 많이 연결되고, 숫자 하나 대신 벡터와 행렬을 다루게 된다. 다음에는 이 규칙을 신경망의 층 단위로 확장해 최종 손실의 기울기가 각 층의 가중치까지 전달되는 과정을 계산할 수 있다.
