여기서 말하는 앙상블이란 여러 모델을 결합해서 하나의 더 강한 예측 모델을 만드는 기법이다. 5장 결정 트리 끝에서 본 랜덤 포레스트가 대표적인 예다. 모델 하나를 더 잘 만드는 대신, 적당한 모델 여러 개의 판단을 모아서 각자의 실수를 서로 지우게 하는 것이 핵심이다.

## 먼저 단어 정리

- **예측기(학습기) :** 앙상블을 이루는 모델 하나하나다. 분류라면 분류기, 회귀라면 회귀 모델이다.
- **약한 학습기 / 강한 학습기 :** 혼자서는 무작위 추측보다 조금 나은 정도의 모델이 약한 학습기다. 깊이 1짜리 결정 트리가 그 예다. 이런 모델들을 결합해 만든 성능 좋은 모델이 강한 학습기다.
- **편향과 분산 :** 3장 회귀에서 본 개념이다. 편향은 가정이 틀려서 생기는 오차로 과소적합으로 나타나고, 분산은 데이터가 조금만 바뀌어도 모델이 크게 바뀌는 성질로 과대적합으로 나타난다. 앙상블 방법마다 둘 중 무엇을 줄이는지가 다르다.
- **부트스트랩 :** 훈련 세트에서 샘플을 **중복을 허용해서**(복원추출) 뽑는 방식이다. 같은 샘플이 여러 번 뽑힐 수도, 한 번도 안 뽑힐 수도 있다.
- **잔차 :** 정답과 예측의 차이(정답 − 예측)다. 모델이 아직 못 맞힌 부분이다.

## 왜 여러 모델을 합치나

지금까지 본 모델은 모두 한쪽으로 기우는 약점이 있었다. 선형 모델은 직선 가정 때문에 과소적합하기 쉬웠고(편향), 결정 트리는 데이터가 조금만 바뀌어도 통째로 바뀌었다(분산). 모델 하나를 더 잘 만드는 데는 한계가 있으니 발상을 바꾼다. **여러 모델을 만들어서 결과를 합치면, 각자의 실수가 서로 상쇄되지 않을까?**

이 발상이 얼마나 강한지 숫자로 보면 놀랍다. 정확도가 51%밖에 안 되는, 동전 던지기보다 겨우 나은 분류기를 서로 **독립적으로** 여러 개 만들어 다수결을 시키면 이렇게 된다.

| 분류기 수 | 다수결이 맞을 확률 |
| --- | --- |
| 1개 | 51% |
| 1,000개 | 약 72.6% |
| 10,000개 | 약 97.7% |

여기서 중요한 조건이 "**독립적으로**"다. 모든 분류기가 같은 곳에서 같은 방향으로 틀리면 다수결도 같이 틀린다. 5장에서 본 식, 평균의 분산 = ρσ² + (1 − ρ)σ²/n이 바로 이 이야기였다. 모델끼리 닮을수록(ρ가 클수록) 합쳐도 나아지지 않는다. 그래서 앙상블의 성능은 **학습기들이 얼마나 다양한가**에 달려 있고, 다양성을 만드는 방법에 따라 앙상블이 세 갈래로 나뉜다.

| 방법 | 다양성을 만드는 법 | 학습 순서 | 주로 줄이는 것 |
| --- | --- | --- | --- |
| 보팅 | 서로 **다른 알고리즘**을 쓴다 | 각자 따로 | 개별 모델의 약점 |
| 배깅 / 페이스팅 (랜덤 포레스트) | 같은 알고리즘에 **다른 데이터 조각**을 준다 | 동시에, 병렬 | 분산 |
| 부스팅 | 앞 모델이 **틀린 부분을 다음 모델**이 고친다 | 차례로, 순차 | 편향 |

앙상블은 단일 모델 성능이 만족스럽지 않을 때, 데이터가 충분히 많고 성능을 더 끌어올리고 싶을 때, 과대적합을 줄이고 일반화 성능을 높이고 싶을 때 쓴다. 사이킷런은 이 방법들을 sklearn.ensemble 모듈에 모아 두었다.

![앙상블 - 7장 — 1번 그림](/images/ai-study/043e30e6f99eff7d9b87.png)

서로 다른 모델이 같은 입력을 보고 예측한다. 중요한 것은 모델의 수만 늘리는 일이 아니라, 틀리는 방식이 충분히 달라지는가이다. 같은 모델을 같은 데이터와 설정으로 복사하면 오류도 거의 같아 합치는 이익이 작을 수 있다.

## 1. 보팅 - 다른 모델들의 투표

가장 단순한 앙상블이다. 로지스틱 회귀, SVM, 결정 트리처럼 **서로 다른 모델**을 각자 학습시키고 예측을 투표로 합친다. 알고리즘이 다르면 틀리는 방식도 다를 가능성이 크기 때문에 다양성이 저절로 생긴다.

투표 방식은 두 가지다.

- **하드 보팅(직접 투표) :** 각 모델이 낸 **클래스**만 세서 다수결로 정한다.
- **소프트 보팅(간접 투표) :** 각 모델이 낸 **확률**을 평균 내서 가장 높은 클래스를 고른다.

| 모델 | 클래스 0 확률 | 클래스 1 확률 |
| --- | --- | --- |
| A | 0.3 | 0.7 |
| B | 0.4 | 0.6 |
| C | 0.2 | 0.8 |
| 평균 | 0.3 | **0.7** |

평균이 큰 클래스 1이 최종 예측이다.

소프트 보팅이 보통 더 잘 맞는 이유는 **자신감을 반영하기 때문**이다. 모델 A와 B는 클래스 1이라고 하지만 확률이 0.51로 겨우 넘었고, 모델 C는 클래스 0이라고 하며 확률 0.99로 아주 확신한다고 해 보자. 하드 보팅은 2대 1로 클래스 1이다. 소프트 보팅은 클래스 1의 평균 확률이 (0.51 + 0.51 + 0.01) / 3 ≈ 0.34라서 클래스 0이다. 하드 보팅은 "겨우 그렇다"와 "확실히 그렇다"를 똑같이 한 표로 세고, 소프트 보팅은 확신이 큰 표에 무게를 더 준다. 다만 모든 모델이 확률을 낼 수 있어야 해서, SVM은 SVC(probability=True)로 확률을 켜야 한다.

실제 예에서 로지스틱 회귀 0.864, SVM 0.888, 결정 트리 0.896이던 정확도가, 셋을 소프트 보팅(VotingClassifier)으로 합치자 **0.904**로 가장 좋은 개별 모델보다 높아졌다.

## 2. 배깅과 페이스팅 - 같은 모델, 다른 데이터

![앙상블 - 7장 — 2번 그림](/images/ai-study/37419e67427c57549fdf.png)

![앙상블 - 7장 — 3번 그림](/images/ai-study/bc0217cec4ed6bf2e304.png)

복원 추출은 뽑은 사례를 다시 후보에 넣으므로 같은 샘플이 한 표본에 여러 번 들어갈 수 있다는 뜻이다. 비복원 추출은 한 표본 안의 중복을 허용하지 않는다. 배깅과 페이스팅의 차이는 이 추출 규칙이고, 모든 모델이 서로 다른 원본 데이터셋에서 출발한다는 뜻은 아니다.

보팅은 서로 다른 좋은 알고리즘을 여러 개 준비해야 한다는 부담이 있다. 다른 길은 **같은 알고리즘을 쓰되, 각 모델에게 훈련 세트의 다른 조각을 주는 것**이다. 데이터가 다르면 같은 알고리즘이라도 다른 모델이 나온다.

- **배깅(bagging = bootstrap aggregating) :** 조각을 **중복을 허용해서**(부트스트랩) 뽑는다. 원래 데이터와 크기가 같은 조각을 복원추출로 만들면, 평균적으로 원래 샘플의 약 63%만 들어가고 일부는 여러 번 들어간다.
- **페이스팅(pasting) :** 조각을 **중복 없이** 뽑는다.

모든 예측기가 학습을 마치면 예측을 모은다. 분류는 가장 많이 나온 클래스(하드 보팅)로, 확률을 낼 수 있는 모델이면 predict\_proba()의 평균(소프트 보팅)으로 정하고, 회귀는 예측값의 평균을 낸다.

효과는 **편향은 비슷하고 분산은 줄어드는 것**이다. 각 모델은 데이터의 일부만 봐서 개별로는 조금 부정확할 수 있지만, 각자 다른 잡음에 흔들리기 때문에 평균을 내면 그 흔들림이 상쇄된다. 결정 트리 하나와, 같은 데이터로 만든 결정 트리 500개짜리 배깅 앙상블을 비교하면 차이가 분명하다. 트리 하나는 결정 경계가 외톨이 점들을 따라 들쭉날쭉한 반면, 배깅 앙상블은 틀린 개수는 비슷한데(편향이 비슷함) 경계가 훨씬 매끄러워서(분산이 작음) 일반화가 더 잘 된다.

각 모델이 서로를 모른 채 따로 학습하므로 **병렬로 학습**할 수 있다. 사이킷런에서는 BaggingClassifier(분류)와 BaggingRegressor(회귀)를 쓴다.

![앙상블 - 7장 — 4번 그림](/images/ai-study/98082506ec2917a7c211.png)

개별 트리의 들쭉날쭉한 경계가 여러 표본의 트리를 결합하면 안정되는 모습을 볼 수 있다. 평균이 도움이 되는 이유는 독립적인 잡음이 서로 상쇄되기 때문이다. 트리들이 비슷한 실수를 반복하면 효과가 줄어든다.

같은 분산 σ²를 가진 모델 M개의 오차 상관이 대략 ρ라고 놓으면 평균 오차의 분산은 σ² × \[ρ + (1 − ρ)/M\]이다. 상관이 1이면 모델 수를 늘려도 이 식의 분산은 줄지 않는다. 랜덤 포레스트가 샘플뿐 아니라 특성 후보도 바꾸는 동기가 이 관계에 있다.

### 특성 샘플링 - 데이터 대신 특성을 나눠 주기

샘플 대신, 또는 샘플과 함께 **특성**을 무작위로 일부만 골라 각 모델에게 줄 수도 있다.

- **랜덤 패치 방식 :** 샘플도 무작위로 고르고 특성도 무작위로 고른다.
- **랜덤 서브스페이스 방식 :** 샘플은 전부 쓰고(bootstrap=False), 특성만 무작위로 고른다(bootstrap\_features=True).

특성이 수백, 수천 개인 고차원 데이터에서 특히 유용하다. 모델마다 보는 특성이 달라지니 다양성이 커지고 분산이 줄어 일반화가 좋아진다. 대신 각 모델이 특성의 일부만 보고 판단하므로 **편향이 조금 올라갈 수 있다.** 다양성과 개별 정확도를 맞바꾸는 거래다.

## 3. 랜덤 포레스트 - 배깅 + 특성 무작위 선택

![앙상블 - 7장 — 5번 그림](/images/ai-study/ee6dc6bf74411a89c3fb.png)

트리마다 다르게 그은 경계를 마지막에 결합한다. 분류 결합을 다수결로 설명하는 것은 직관에 도움이 되지만, scikit-learn의 RandomForestClassifier는 각 트리의 클래스 확률을 평균한 뒤 가장 큰 클래스를 선택한다. 각 트리가 고른 클래스의 단순 다수결과 결과가 항상 같지는 않다.

특성 중요도는 인과관계의 크기가 아니다. 불순도 감소를 합한 중요도는 값의 종류가 많거나 상관된 특성이 있을 때 해석이 까다롭다. 중요도가 높다는 사실만으로 그 특성을 바꾸면 공격이 줄어든다고 결론 내릴 수는 없다.

랜덤 포레스트는 **결정 트리에 배깅(또는 페이스팅)을 적용한 앙상블**에 무작위성을 한 겹 더 넣은 것이다. 보통의 결정 트리는 노드를 나눌 때 **모든 특성** 중에서 최선의 질문을 찾지만, 랜덤 포레스트의 트리는 노드마다 **무작위로 고른 일부 특성** 중에서만 최선의 질문을 찾는다. 그래서 트리를 다르게 만드는 무작위성이 두 군데 들어간다. 트리마다 다른 데이터 샘플(부트스트랩), 분할마다 다른 특성 후보다. 5장에서 본 것처럼 이 장치가 트리끼리 덜 닮게 만들어서, 트리 하나하나의 편향은 조금 손해 보지만 분산이 크게 줄어 전체적으로 더 좋은 모델이 된다.

예측은 회귀면 모든 트리의 예측을 평균 내고, 분류면 모든 트리의 예측을 모아 가장 많이 선택된 클래스를 고른다.

**왜 더 좋은 경계가 나오나.** 부트스트랩 때문에 어떤 훈련 점은 한 트리에는 있고 다른 트리에는 없어서, 트리 하나하나는 불완전하다. 무작위 트리 5개의 결정 경계를 따로 그려 보면 각자 엉뚱한 곳이 다르게 휘어 있다. 그런데 다섯 트리의 확률을 평균 낸 랜덤 포레스트의 경계는 어느 트리보다 덜 과대적합되고 매끄럽다. 각 트리가 외운 잡음은 트리마다 달라서 평균에서 지워지고, 진짜 패턴만 남기 때문이다.

**특성 중요도.** 랜덤 포레스트의 또 다른 장점이다. 사이킷런은 어떤 특성을 쓴 노드가 평균적으로 불순도를 얼마나 줄였는지를 모든 트리에 걸쳐 계산해서 특성의 중요도를 낸다. 붓꽃 데이터에 트리 500개짜리 랜덤 포레스트를 학습시키면 이렇게 나온다.

| 특성 | 중요도 |
| --- | --- |
| 꽃잎 길이 | 0.44 |
| 꽃잎 너비 | 0.42 |
| 꽃받침 길이 | 0.11 |
| 꽃받침 너비 | 0.02 |

5장에서 트리가 꽃잎 두 특성만으로 질문을 만들었던 이유가 숫자로 확인된다. 보안에서는 "어떤 트래픽 특징이 탐지에 가장 많이 기여했나"를 보는 데 쓴다.

짚어 둘 점이 하나 있다. 랜덤 포레스트는 결정 트리의 약한 일반화를 보완하려고 만들었다고 소개되는데, 그 말은 **훈련 범위 안에서** 맞다. 흔들림이 줄어서 새 데이터에 더 잘 맞는다. 하지만 **훈련 범위 밖**을 예측하지 못하는 약점은 그대로다. 랜덤 포레스트의 답도 결국 리프 값들의 평균이고, 리프 값은 훈련 샘플의 평균이기 때문이다. 5장의 램 가격 예처럼 추세를 이어 그려야 하는 문제에는 랜덤 포레스트도 맞지 않는다.

## 4. 부스팅 - 앞 모델의 실수를 다음 모델이 고친다

![앙상블 - 7장 — 6번 그림](/images/ai-study/0e1d4339949d14178316.png)

배깅의 각 모델은 독립적으로 준비할 수 있지만, 부스팅의 다음 모델은 앞 단계 결과를 필요로 한다. 그래서 단계 사이의 병렬화는 제한된다. 다만 각 단계에서 분할 후보를 찾는 내부 계산까지 모두 병렬화할 수 없다는 뜻은 아니다.

배깅은 깊고 복잡한 모델(분산이 큰 모델)을 여러 개 만들어 평균 내서 **분산**을 줄였다. 그렇다면 반대로, 너무 단순해서 과소적합하는 모델(편향이 큰 모델)은 어떻게 할까. 단순한 모델을 아무리 많이 평균 내도 다 같이 단순할 뿐이다.

부스팅은 다른 길로 간다. **약한 모델들을 차례로 학습시키면서, 각 모델이 앞 모델이 틀린 부분을 보완하게 한다.** 약한 학습기는 보통 깊이 1짜리 결정 트리처럼 표현력이 제한된 모델도 많이 사용하며, 수십\~수백 개를 이어 붙이면 점점 정교해진다. 그래서 부스팅은 **편향을 줄이는 데** 효과적이다. 대표 알고리즘은 아다부스트, 그래디언트 부스팅, 그리고 그래디언트 부스팅을 개선한 XGBoost와 LightGBM이다.

단점은 각 모델이 앞 모델의 결과를 보고 학습하므로 **병렬화할 수 없다**는 것이다. 그래서 배깅이나 페이스팅만큼 큰 데이터로 확장하기 어렵다.

|  | 배깅 | 부스팅 |
| --- | --- | --- |
| 개별 모델 | 깊고 복잡하다 (분산이 크다) | 얕고 단순하다 (편향이 크다) |
| 학습 순서 | 동시에, 서로 모른다 | 차례로, 앞 모델을 보고 고친다 |
| 줄이는 것 | 분산 | 편향 |
| 병렬화 | 가능하다 | 불가능하다 |

## 5. 아다부스트 - 틀린 샘플에 무게를 싣는다

아다부스트(AdaBoost, Adaptive Boosting)는 앞 모델이 틀린 **샘플**을 다음 모델이 더 신경 쓰게 만든다. 방법은 **샘플마다 가중치**를 두고 틀린 샘플의 가중치를 키우는 것이다. 가중치가 큰 샘플은 다음 모델이 학습할 때 비용에 더 크게 반영되므로, 다음 모델은 그 샘플을 맞히려고 애쓴다. 가중치를 반복해서 조정(adapt)한다고 해서 이름이 아다부스트다.

### 학습 과정

1. **시작 :** 모든 샘플에 같은 가중치 w = 1/m을 준다(m은 샘플 수).
2. **모델 학습 :** 현재 가중치로 모델을 학습하고 예측한다.
3. **에러율 계산 :** 틀린 샘플들의 가중치 합이 전체 가중치 합에서 차지하는 비율이 **가중치가 적용된 에러율 r**이다. 그냥 틀린 개수가 아니라, 중요한 샘플을 틀릴수록 에러율이 커진다.
4. **모델 가중치 계산 :** 이 모델이 최종 투표에서 얼마나 큰 목소리를 낼지 정한다. 모델이 정확할수록 가중치가 크다.
5. **샘플 가중치 갱신 :** 이 모델이 **틀린** 샘플의 가중치에 exp(α)를 곱하고, 맞힌 샘플은 그대로 둔다. 그다음 전체 가중치 합으로 나눠 정규화한다.
6. **반복 :** 갱신된 가중치로 다음 모델을 학습한다. 정해 둔 모델 수에 도달하거나 완벽한 모델이 나오면 멈춘다.

```txt
에러율       r_j = (틀린 샘플들의 가중치 합) / (전체 가중치 합)
모델 가중치  α_j = η × log((1 − r_j) / r_j)        η = 학습률
샘플 가중치  틀린 샘플은 w ← w × exp(α_j),  맞힌 샘플은 그대로
```

숫자를 넣어 보면 식의 뜻이 보인다(η = 1).

| 모델의 에러율 r | 모델 가중치 α | 틀린 샘플의 가중치 배율 | 의미 |
| --- | --- | --- | --- |
| 0.1 | 2.20 | 9배 | 잘 맞히는 모델이라 목소리가 크다. 그런데도 틀린 샘플은 정말 어려운 샘플이니 크게 강조한다 |
| 0.3 | 0.85 | 2.33배 | 그럭저럭인 모델 |
| 0.5 | 0 | 1배 | 동전 던지기와 같다. 투표권이 없고 가중치도 안 바꾼다 |

### 예측

모든 모델의 예측을 모델 가중치 α로 가중 투표한다. 잘 맞힌 모델일수록 최종 예측에 더 크게 반영된다.

| 모델 | 예측 | 가중치 α | α × 예측 |
| --- | --- | --- | --- |
| h₁ | +1 | 0.7 | +0.7 |
| h₂ | +1 | 0.6 | +0.6 |
| h₃ | −1 | 0.3 | −0.3 |
| 합 |  |  | **+1.0 → 양성** |

초승달 데이터에 아다부스트로 모델 5개를 차례로 붙여 보면, 첫 모델이 많이 틀린 샘플들의 가중치가 커져서 두 번째 모델은 그 샘플들을 더 정확히 맞히는 쪽으로 경계를 옮긴다. 이렇게 모델이 추가될 때마다 경계가 조금씩 고쳐진다. 학습률 1이면 매번 크게 고쳐서 경계가 크게 흔들리고, 학습률 0.5면 고치는 폭이 절반이라 경계가 차분하게 움직인다. 과대적합하면 모델 수를 줄이거나 약한 학습기를 더 강하게 규제한다.

오차가 큰 샘플에 집중하는 회귀 버전(AdaBoostRegressor, AdaBoost.R2)도 있지만 성능과 안정성에 한계가 있어 거의 쓰이지 않고, 아다부스트는 주로 분류에 쓴다. 사이킷런에서는 AdaBoostClassifier에 깊이 1짜리 결정 트리를 약한 학습기로 넣어 쓴다.

## 6. 그래디언트 부스팅 - 남은 오차를 다음 모델이 맞힌다

![앙상블 - 7장 — 7번 그림](/images/ai-study/bca386e8467f06e8a3b4.png)

![앙상블 - 7장 — 8번 그림](/images/ai-study/bdcdf8070ca8c00e5ec9.png)

왼쪽 열은 새 트리가 현재 잔차를 맞히는 모습이고, 오른쪽 열은 지금까지의 트리를 더한 최종 예측이다. 새 트리는 새 샘플의 실제 잔차를 알고 계산하는 것이 아니다. 훈련 데이터에서 입력과 잔차의 관계를 학습해 새 입력에도 보정량을 예측한다.

아다부스트는 틀린 **샘플의 가중치**를 바꿔서 다음 모델의 관심을 돌렸다. 그래디언트 부스팅은 더 직접적이다. **다음 모델에게 "앞 모델이 못 맞힌 나머지(잔차)"를 정답으로 주고 학습시킨다.**

회귀로 따라가 보면 바로 이해된다.

1. **첫 번째 트리 h₁ :** 원래 정답 y를 학습한다. 곡선 데이터를 깊이 2짜리 트리로 맞히면 계단 4칸으로 대충만 따라간다.
2. **잔차 계산 :** 각 샘플에서 y − h₁(x)를 구한다. 첫 트리가 너무 낮게 예측한 곳은 양수, 너무 높게 예측한 곳은 음수다.
3. **두 번째 트리 h₂ :** 원래 정답이 아니라 **이 잔차**를 정답으로 학습한다. "첫 트리가 어디서 얼마나 틀렸나"를 배우는 것이다.
4. **세 번째 트리 h₃ :** h₁ + h₂가 아직 못 맞힌 잔차를 학습한다.
5. **예측 :** 모든 트리의 예측을 **더한다.** h(x) = h₁(x) + h₂(x) + h₃(x).

h₁만 썼을 때는 계단이 거칠다가, h₂를 더하면 곡선 바닥 쪽이 맞춰지고, h₃까지 더하면 양 끝까지 더 정확해진다. 트리를 더할수록 남은 잔차가 0 쪽으로 줄어든다. 참고로 샘플 4개(x = 1, 2, 3, 4, 정답 3.0, 3.5, 4.0, 5.0)에 깊이 2 트리를 세 개 잇는 예제를 직접 계산해 보면, 이 데이터와 분할 규칙에서는 두 번째 트리에서 잔차가 0이 되어 세 번째 트리는 0만 예측한다. 원리를 보여 주는 예제이지 일반화를 보여 주는 예제는 아니다.

### 이름에 "그래디언트"가 붙은 이유

업데이트 식을 보면 3장의 경사 하강법과 똑같은 모양이다.

```txt
ŷ_new = ŷ_old − η × g        g = ∂L/∂ŷ  (손실 함수를 예측값으로 미분한 기울기)
```

손실이 MSE(½(y − ŷ)²)라면 g = ŷ − y, 즉 **잔차에 마이너스를 붙인 것**이다. 그래서 "기울기의 반대 방향으로 간다"는 것은 "잔차만큼 예측을 고친다"와 같은 말이다. 경사 하강법은 θ를 조금씩 옮겨 비용을 줄였는데, 그래디언트 부스팅은 **예측값 자체를** 조금씩 옮겨 비용을 줄이고, 그 한 걸음을 트리 하나가 맡는다. 현재 모델이 잘못 예측한 방향을 다음 모델이 조금씩 수정하는 것이다.

### 트리 수와 학습률

![앙상블 - 7장 — 9번 그림](/images/ai-study/18f4d384104561c29eee.png)

![앙상블 - 7장 — 10번 그림](/images/ai-study/0747a1a59dd4d6a43075.png)

트리를 적게 두면 큰 흐름을 덜 배우고, 너무 많이 더하면 잡음까지 보정할 수 있다. 오른쪽 그림처럼 검증 오차가 가장 작았던 트리 수를 선택한다. 학습률을 낮추면 각 트리의 기여가 작아져 보통 더 많은 트리가 필요하므로 두 값을 함께 조정한다.

- **η(학습률) :** 각 트리의 기여를 얼마나 줄여서 더할지 정한다. 작게 하면 트리가 더 많이 필요하지만 일반화가 좋아지는 경향이 있다(축소, shrinkage).
- **트리가 너무 적으면 :** 트리 3개로는 훈련 세트도 제대로 따라가지 못한다. 과소적합이다.
- **트리가 너무 많으면 :** 트리 200개면 계단이 훈련 점 하나하나를 따라가서 과대적합한다.

그래서 트리 수는 **조기 종료**로 정한다. 트리를 하나씩 더하며 검증 오차를 재 보면, 오차가 내려가다가 어느 지점(예시에서는 트리 56개)에서 가장 낮고 그 뒤로는 다시 조금씩 올라간다. 그 지점의 모델을 쓴다. 3장 규제에서 본 조기 종료와 같은 아이디어다.

### 손실 함수

분류(GradientBoostingClassifier)는 로그 손실(이진 크로스 엔트로피)을, 회귀(GradientBoostingRegressor)는 MSE를 쓴다. 손실만 바꾸면 "기울기를 따라 예측을 고친다"는 같은 절차가 그대로 작동한다. 회귀 트리를 이어 붙인 이 모델을 GBRT(Gradient Boosted Regression Trees)라고도 부른다.

## 7. XGBoost - 그래디언트 부스팅의 고성능판

그래디언트 부스팅은 성능이 좋지만 느리고 과대적합하기 쉽다. XGBoost(eXtreme Gradient Boosting)는 이 둘을 공학적으로 개선한 버전이다. 분류와 회귀 모두에 쓰이고, 가장 널리 쓰이는 부스팅 기법 중 하나이며, 대규모 데이터와 고차원 데이터에서 빠르고 정확하다.

| 특징 | 무슨 뜻인가 |
| --- | --- |
| 규제 | 라쏘(L1)와 릿지(L2) 규제를 모두 지원한다. 3장의 그 규제를 트리에 걸어 과대적합을 막는다 |
| 병렬화 | 트리를 차례로 만드는 부스팅의 순서 자체는 그대로다. 대신 **트리 하나 안에서** 각 노드의 최선의 분할을 찾는 계산을 병렬로 나눠 학습 속도를 크게 높인다 |
| 조기 종료 | 성능 향상이 멈추면 트리를 더 붙이지 않는다 |
| 트리 가지치기 | 이득이 없는 분할을 잘라 내서 트리 복잡도를 제한한다 |
| 결측값 처리 | 값이 비어 있는 샘플을 어느 쪽 가지로 보낼지 스스로 학습해서, 별도 전처리 없이 결측값이 있는 데이터를 다룬다 |
| 사용자 정의 목적 함수 | 손실 함수를 직접 정의할 수 있어 모델링이 유연하다 |

XGBoost는 사이킷런에 들어 있지 않아서 xgboost 라이브러리를 따로 설치한다. 붓꽃 3품종 분류에 쓰면 목적 함수를 multi:softmax로, 평가 지표를 mlogloss로 둔다. 3장에서 본 소프트맥스와 크로스 엔트로피가 부스팅의 손실로 그대로 쓰이는 것이다. eta는 학습률이고, 부스팅 라운드 수는 붙일 트리 수다.

## 8. LightGBM - 더 빠르고 가볍게

LightGBM(Light Gradient Boosting Machine)도 그래디언트 부스팅에 기반한다. 2017년 Microsoft가 만들었고, XGBoost보다 더 빠르고 가볍게 동작하도록 설계됐다. 대용량 데이터 처리에 최적화돼 있고 GPU 학습을 지원하며, 사이킷런과 비슷하게 쓸 수 있는 별도 라이브러리(lightgbm)로 제공된다.

- **XGBoost :** 정확도 중심의 안정형이다.
- **LightGBM :** 속도 중심의 대용량형이다.

수백만 건의 트래픽 로그처럼 큰 보안 데이터에서는 LightGBM이 학습 시간 면에서 유리한 경우가 많다.

## 9. 앙상블의 장점과 단점

**장점**

- **성능 :** 개별 모델보다 일반적으로 더 높은 성능을 낸다.
- **과대적합 방지 :** 여러 모델의 평균적인 판단이라서 잡음과 이상치에 강하고, 예측이 안정적이다.

**단점**

- **비용 :** 모델을 여러 개 학습하고 예측해야 해서 계산 비용이 크고 느릴 수 있다. 특히 부스팅은 병렬화도 안 된다.
- **해석 :** 여러 모델의 출력을 조합하기 때문에 해석이 어렵다. 5장에서 본 것처럼 트리 하나는 화이트박스였지만, 트리 수백 개의 투표나 합은 블랙박스가 된다. 탐지 모델이 경보를 띄웠을 때 "왜"를 설명하기 어려워진다.
- **튜닝 :** 데이터 준비와 하이퍼파라미터 튜닝이 중요하다. 트리 수, 깊이, 학습률을 잘못 잡으면 과대적합이나 과소적합으로 바로 이어진다.

## 앙상블 단원을 마무리하며

1. 모델 하나에는 편향이나 분산의 약점이 있으니, 여러 모델을 합쳐 실수를 상쇄한다. 단, **모델들이 서로 달라야** 한다.
2. 다른 알고리즘을 모아 투표시키면 **보팅**이다. 확률을 평균 내는 소프트 보팅이 보통 더 낫다.
3. 같은 알고리즘에 다른 데이터 조각을 주면 **배깅/페이스팅**이다. 병렬로 학습하고 **분산**을 줄인다. 여기에 분할마다 특성 무작위 선택을 더한 트리 앙상블이 **랜덤 포레스트**다.
4. 약한 모델을 차례로 이어 앞 모델의 실수를 고치게 하면 **부스팅**이다. **편향**을 줄이지만 병렬화가 안 된다. **아다부스트**는 틀린 샘플의 가중치를 키우고, **그래디언트 부스팅**은 남은 잔차를 다음 트리가 맞힌다. 후자는 예측값에 대한 경사 하강법이다.
5. **XGBoost**는 규제, 병렬화, 결측값 처리로 그래디언트 부스팅을 강하게 만들었고, **LightGBM**은 그것을 더 빠르고 가볍게 만들었다.
6. 대가는 계산 비용, 해석력 상실, 튜닝 부담이다.

## 세 종류의 가중치를 서로 구분하기

아다부스트의 샘플 가중치는 **어느 훈련 데이터를 더 중요하게 볼지**를 정한다. 예측기 가중치 α는 **최종 결합에서 어느 모델의 표를 더 크게 셀지**를 정한다. 신경망의 연결 가중치는 **뉴런 사이의 값을 어떻게 변환할지**를 정한다. 모두 가중치라는 이름을 쓰지만 붙어 있는 대상과 역할이 다르다.

이진 AdaBoost의 한 가지 표기에서는 예측기 계수를 1/2 × log((1 − r)/r)로 두고 모든 샘플에 exp(−αyh)를 곱한다. 다른 표기에서는 계수를 log((1 − r)/r)로 두고 틀린 샘플에만 exp(α)를 곱한 뒤 정규화한다. 학습률을 같게 두면 두 표기의 상대적인 샘플 비율은 같다. 두 공식에서 절반 계수와 갱신 규칙을 하나씩 섞으면 다른 알고리즘이 되므로, 한 쌍으로 읽어야 한다.

소프트 보팅의 높은 확신은 정확한 확률 추정을 전제로 도움이 된다. 잘못된 모델이 과도하게 확신하면 오히려 해가 될 수 있다. XGBoost의 L1·L2 규제는 트리 잎의 출력 가중치 등에 적용하는 목적함수의 규제이며, 입력 특성마다 선형 회귀 계수를 줄이는 것과 구조가 그대로 같지는 않다. LightGBM과 XGBoost의 속도·성능 우열도 데이터 크기, 장치, 구현과 설정에 따라 달라진다. [scikit-learn 앙상블 설명](https://scikit-learn.org/stable/modules/ensemble.html)

이 장까지는 주어진 특성을 여러 방식으로 조합해 예측했다. 다음 [딥러닝의 기본 개념 - 8장](/post/ai-foundations-11-deep-learning)에서는 입력을 어떤 특성으로 바꿀지도 여러 층의 매개변수로 함께 학습한다.
